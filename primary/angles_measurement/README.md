## 课件结构

### 一、动画课堂（5 个模块，可交互）

1. **角的组成** —— 一条边转动生成角，实时标注顶点/两条边/∠AOB，滑块可调角度，动画可播放。
2. **什么是 1 度** —— 360° 圆盘，指针旋转并同步报数；一键转到直角 90°、平角 180°、周角 360°。
3. **量角器的用法**（核心）—— 真·可交互量角器，按"① 点对点 → ② 线对线 → ③ 读内外圈"三步分步演示；
   锐角高亮**内圈**读数、钝角自动翻转量角器高亮**外圈**读数；滑块可任选 15°~165° 的角。
4. **角的分类** —— 一条边转一圈，实时显示锐角/直角/钝角/平角/周角。
5. **角的大小** —— 三个角对比 + "把边拉长"按钮，直观说明**角的大小与边长短无关**。

### 二、分层练习（共 37 题，答完即时反馈）

| 组别 | 题量 | 题型 |
|---|---|---|
| 巩固练习（基础过关） | 16 | 选择 12 + 填空 4 |
| 动手量一量 | 6 | 看图量角（可点"看量角器"核对，含内外圈读反的陷阱题） |
| 扩展练习（思维提升） | 15 | 选择 4 + 填空 11 |

- 答错只给**提示**不给答案，答对给**解析**；每组可单独"重做本组"，右上角实时计分；
- 页面末尾"答案与解析"可折叠展开，供教师讲评或打印。

### 三、使用建议

- **上课演示**：浏览器全屏（F11），按顶部导航依次点击各模块；
- **学生练习**：同一份文件发到学生电脑，选择作答 → 展开答案自评；
- **打印**：先展开"答案与解析"，再按 Ctrl/Cmd+P（已内置打印样式，隐藏按钮与导航栏）。

## 自检（可选）

```bash
pip install playwright && playwright install chromium
python3 tests/test_courseware.py
```

四层检查：结构（文件齐/无外部引用）、内容（题数=答案数）、交互（按钮可用/零报错）、
视觉（取角弧实际渲染中点换算极角，验证落在角的中分线上）。
用来防止"弧线画反方向"这类肉眼容易漏、但会误导学生的问题再次出现。
