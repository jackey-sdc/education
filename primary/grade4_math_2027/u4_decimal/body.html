1小数的意义

动画十格图：小数就是"平均分"的一部分

拖动滑块改变涂色格数，看十格图表示的小数。
教学口径：把"1"平均分成 10 份，其中1 份是 0.1，3 份是 0.3； 平均分成 100 份，其中 1 份是 0.01。
计数单位：0.1、0.01、0.001；相邻两个计数单位之间的进率是 10。

—

2小数的数位顺序表

核心动画数位顺序表里小数部分怎么排

输入一个小数，看它在数位顺序表中的位置。
教学口径：小数点左边是整数部分，右边是小数部分； 小数部分从十分位起，依次是百分位、千分位； 计数单位与数位一一对应（十分位对应 0.1）。

3小数的读法和写法

动画整数部分按整数读，小数部分依次读

点"下一个"，看一个小数是怎么读出来、又怎么写下来的。
教学口径：整数部分按整数的读法读；小数点读作"点"； 按原数逐位读时，小数部分要依次读出每一个数字，末尾的 0 也要读（0.50 读作零点五零）； 若先把它化简成 0.5，则读作“零点五”。
注意：小数部分中间有 0 一定要读出来（如 2.405 读作二点四零五）。

4小数的性质

核心动画小数末尾添上 0，大小不变

点"添 0"或"去 0"，看数轴上的点动没动。
教学口径：小数的末尾添上 0 或去掉 0，小数的大小不变； 所以小数可以化简（去 0）和改写（添 0）。
关键区别：小数中间的 0 不能去掉（0.305 ≠ 0.35）；小数末尾的 0 可以去掉（0.50 = 0.5，100.50 = 100.5），但整数部分的 0 不能乱去（100.05 ≠ 1.5）。

5大小比较与单位换算

动画小数的大小比较

点"比一比"，看两个小数在数轴上的位置。
教学口径：先比整数部分，整数部分相同就依次比十分位、百分位……， 位数多的小数不一定大（0.5 < 0.48）。

动画小数点移动引起大小变化

点"移动小数点"，看数的大小怎么变。
教学口径：小数点向右移一位（多位），扩大到原数的 10 倍（100 倍……）； 向左移一位（多位），缩小到原数的 1/10（1/100……）。
