# 第四单元《小数的认识》教学设计

> 人教版（2024 年审定）四年级数学下册 · 配套课件 `index.html`（8 个课时）

## 一、教材分析

小数是继整数之后数的第二个体系，也是小学阶段最重要的"数"的认识。
它的难点**不在读读写写，而在"数位"这个新维度**：
整数只有"个、十、百"，小数引入了"十分位、百分位"，
计数单位从 1 细化到 0.1、0.01、0.001。

本单元的三条主线：
**意义（十格图）→ 数位（顺序表）→ 性质与比较（数轴）**。
其中**小数的性质**是全单元的枢纽：它解释了为什么 0.5 = 0.50，
也解释了为什么 0.305 ≠ 0.35（末尾 vs 中间）。
课件把这条规律做成**数轴上两个点是否重合**的动画，让"相等"变得可见。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 理解小数的意义与计数单位；掌握数位顺序表；会读会写小数；掌握小数的性质；会比较大小；知道小数点移动引起大小变化的规律；会进行单位换算 |
| 过程方法 | 在十格图与分数的对照中建立小数意义；借助数位顺序表理解数位与计数单位的对应 |
| 情感态度 | 体会"十进制"思想在小数中的延续；养成"先对齐数位再比较"的严谨习惯 |

## 三、教学重点与难点

- **重点**：小数的意义与计数单位；数位顺序表；小数的性质；小数的大小比较。
- **难点**：**数位与计数单位一一对应**（0.405 中 4 在什么位？表示多少）；
  **小数的性质的"末尾"限制**（中间的 0、整数部分的 0 都不能动）；
  **位数多的小数不一定大**（0.5 > 0.48）。

## 四、教学准备

课件 `index.html`（投影）、方格纸（画十格图）、数轴挂图、小棒（每 10 根一捆）。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 小数的意义 | ① 小数的意义 | 十格图涂色，建立 0.1 与分数 1/10 的对应 |
| 2 | 小数的计数单位 | ① 小数的意义 | 0.1 / 0.01 / 0.001，相邻进率 10 |
| 3 | 数位顺序表 | ② 数位顺序表 | 把小数填进数位表，数位与计数单位对应 |
| 4 | 小数的读法 | ③ 读法和写法 | 整数按整数读，小数部分逐位读 |
| 5 | 小数的写法 | ③ 读法和写法 | 反向由读法写数 |
| 6 | 小数的性质 | ④ 小数的性质 | 数轴上两个点重合；0.305 ≠ 0.35 |
| 7 | 大小比较与小数点移动 | ⑤ 大小比较 | 先整数部分，再十分位；右移扩大左移缩小 |
| 8 | 整理与复习 | 练习区 | 三档练习 + 错题讲评 |

### 课堂节奏（以第 6 课时"小数的性质"为例）

1. **复习（3 分钟）**：课件第 ① 模块，10 格图涂 5 格，问"0.5 和 0.50 一样吗？"
2. **猜想（5 分钟）**：学生猜"一样"，课件第 ④ 模块把两个小数都标到数轴上，
   **两个点完全重合**——用可视证据代替口头断言。
3. **辨析（10 分钟）**：课件第 ④ 模块切到 0.305 与 0.45 的对照，
   学生的"一样"被推翻。追问："为什么 0.50 能去 0 而 0.305 不能？"
   → 引出**只有末尾的 0 能去**。
4. **拓展（8 分钟）**：0.5 和 0.50 大小相等，但**计数单位不同**（十分位 vs 百分位），
   这正是本单元"数位"这条线的价值。
5. **练习（8 分钟）**：第一档性质题 + 第二档化简改写题当堂完成。
6. **小结（3 分钟）**：板书——**小数的末尾添上 0 或去掉 0，小数的大小不变**。

## 六、板书设计

```
                     小数的认识
  意义：把"1"平均分成 10 份，1 份是 0.1，3 份是 0.3（= 3/10）
  计数单位：0.1（十分位）0.01（百分位）0.001（千分位）
            相邻两个计数单位之间的进率是 10
  数位顺序表：… 千位 百位 十位 个位 | . | 十分位 百分位 千分位 …
              ←—— 整数部分 ——→      ← 小数部分 →
              数位与计数单位一一对应
  读法：整数部分按整数读；小数点读"点"；小数部分依次读每一位
        按原数逐位读：中间的 0 必读，末尾的 0 也要读；化简后按化简结果读
  性质：小数的末尾添上 0 或去掉 0，大小不变
        ★ 只有末尾的 0 能动；中间的 0、整数部分的 0 都不能动
        （正确：0.5 = 0.50、0.50 = 0.5；错误：0.305 = 0.35）
  比较：先整数部分 → 再十分位 → 再百分位 …
        ★ 位数多的小数不一定大（0.5 > 0.48）
  小数点：右移扩大（1 位 10 倍），左移缩小（1 位 1/10）
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 去掉小数中间的 0（0.305 → 0.35） | 课件第 ④ 模块专门用 0.305/0.35 对照，数轴上两点明显分开 |
| 误以为 0.50 和 0.5 不相等（或把末尾的 0 当成不能去） | 课件④用数轴看两点重合；明确末尾的 0 可去，0.50 = 0.5 |
| 认为 0.5 < 0.48（位数多就大） | 课件第 ⑤ 模块数轴演示，并追问"十分位 5 和 4 谁大" |
| 小数部分中间的 0 不读 | 课件第 ③ 模块 3.205 读作"三点二零五"，中间 0 明显读出 |
| 读成"三点二五"（漏 0） | 同上；要求学生逐位指着读 |
| 数位与计数单位对不上（0.405 中 4 在哪） | 课件第 ② 模块把数字填进数位表并标出计数单位 |
| 小数点移动方向记反 | 课件第 ⑤b 模块"右移扩大、左移缩小"；用 0.36→36 实测 |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"10 题（十格图、比较、单位换算）。
- **单元作业**：第三档"扩展思维"10 题（化简、推理、易错辨析）。
- **评价建议**：性质题要求学生**明确指出"动的是哪个位置的 0"**；
  比较题要求说出"先比哪一位"。

## 九、四档分层与星级（2026-10 增补）

本单元的练习按**难度分四档，用星级标注**：

| 档位 | 星级 | 定位 | 用法 |
|---|---|---|---|
| 第一档 巩固基础 | ★★★ | 随堂练 | 课堂当堂完成，5 分钟 |
| 第二档 动手操作 | ★★★ | 读图 / 操作 | 课堂或课后，边做边学 |
| 第三档 扩展思维 | ★★★★ | 拓展题 | 单元作业主力 |
| 第四档 五星挑战 | ★★★★★ | 浅奥思维 | 选做，供学有余力的学生 |

**第四档题目的共同特征**：都需要**两步以上**的思考——
先从已知条件里"倒推"出中间量，再用本单元的规律求解；
或需要在两个结论之间做**辨析**（如"等腰三角形一个角是 40°，顶角是 100°"要分两种情况讨论）。

### 鼓励机制

学生**答对四星或五星题**时，页面会给出正反馈：
- **四星题**：「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：**「你好棒！」**横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 Web Audio 实时合成，**不引用任何外部音频文件**，
> 课件保持"单文件、零外部依赖、离线可用"。

**教学建议**：不要把"做对几道题"当成评价目标。
星级只是**难度标识**，真正的评价要看学生**能不能说清自己用了哪条规律、为什么这样想**。
五星题答错是正常的——它的价值恰恰在于让学生体验"想不出来"的过程，
教师可借此追问："你卡在哪一步？如果把这道题拆成两步，第一步你能做吗？"
