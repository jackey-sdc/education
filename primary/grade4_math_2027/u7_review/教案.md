# 第七单元《复习与关联》教学设计

> 人教版（2024 年审定）四年级数学下册 · 配套课件 `index.html`（5 个课时）

## 一、教材分析

这是全册的收口单元。与"把知识点再过一遍"不同，
新课标强调"**整理与关联**"——让学生看见知识之间的**结构**。

本册的结构其实非常清晰：
- **数与代数**：除法（算理）→ 运算律（算巧）→ 小数（数位与算法）
- **图形与几何**：三角形（特性 → 三边 → 分类 → 内角和 → 高）
- **统计**：数据 → 平均数 → 决策

课件第 ② ③ ④ 模块就是把���三条线画出来：
第 ② 模块的"算理 → 数位 → 算巧"链条、第 ③ 模块的"三角形知识链"，
第 ④ 模块的"收集 → 整理 → 求平均数 → 决策"流程。
第 ⑤ 模块用一个综合题把全册串起来。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 梳理全册知识结构；掌握各单元核心算法与算理；能综合运用多单元知识解决实际问题 |
| 过程方法 | 在整理与关联中形成结构化认识；经历"读题—分问—选法—计算—检验"的完整解题过程 |
| 情感态度 | 体验数学知识之间的内在联系；形成"先想清楚用什么方法"的习惯 |

## 三、教学重点与难点

- **重点**：各单元核心知识的系统整理与结构化理解。
- **难点**：**知识之间的关联**（不是并列罗列，而是互相支撑）；
  **综合题中"每一问分别用什么方法"的分步思考**。

## 四、教学准备

课件 `index.html`（投影）、本册六个单元的课件（复习时回翻）、错题本。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 全册知识地图 | ① 全册知识地图 | 点开 7 大板块，梳理本册学了什么 |
| 2 | 数与代数整理 | ② 数与代数整理 | 三条主线：算理 → 数位 → 算巧 |
| 3 | 图形与几何整理 | ③ 图形与几何整理 | 三角形知识链：四块知识互相支撑 |
| 4 | 统计整理 + 综合应用 | ④ 统计整理 / ⑤ 综合应用 | 数据 → 平均数 → 决策；综合题串全册 |
| 5 | 单元检测与讲评 | 练习区 | 三档练习 + 典型错题讲评 |

### 课堂节奏（以第 4 课时"综合应用"为例）

1. **铺垫（5 分钟）**：课件第 ④ 模块回顾统计流程——
   **收集 → 整理 → 求平均数 → 决策**。
2. **出题（5 分钟）**：课件第 ⑤ 模块的综合题（租车春游），
   先让学生自己读题，圈出"求的是什么"。
3. **分问（8 分钟）**：课件第 ⑤ 模块逐步演示：
   ① 读题找问题 → ② 求车数（**进一法**，来自第一单元）
   → ③ 求各项费用 → ④ 求总钱与人均（**平均数**，来自第六单元）。
   让学生看到**一题串起多个单元**。
4. **迁移（10 分钟）**：换人数（拖动滑块 10→50），让学生发现
   **总钱数随人数变，人均随人数变**，但"该用什么方法"不变。
5. **小结（4 分钟）**：板书——**综合题三步走：找问题 → 选方法 → 算并检验**。

## 六、板书设计

```
                    复习与关联
  本册三条主线：
    数与代数：除法（算理）→ 运算律（算巧）→ 小数（数位与算法）
    图形与几何：三角形（特性→三边→分类→内角和→高）
    统计：收集数据 → 整理数据 → 求平均数 → 作出决策
  各单元核心（速查）：
    一 除数是两位数的除法：看作整十数试商；商大调小、商小调大；进一法/去尾法
    二 混合运算和运算律：先乘除后加减；五大运算律；分配律可正用可逆用
    三 三角形：任意两边之和大于第三边；内角和 180°；等边⊂等腰；3 条高
    四 小数的认识：十分位/百分位/千分位；计数单位进率 10；只有末尾的 0 能动
    五 小数加减法：小数点对齐（相同数位）；得数小数点对齐；运算律可推广
    六 平均数：总数 ÷ 份数；人数相同比总数，人数不同比平均数
  综合题三步走：① 找问题（求什么）② 选方法（用哪条知识）③ 算并检验
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 复习变成"知识点重讲" | 课件第 ① ③ 模块都强调**关联**：三边关系支撑分类与内角和 |
| 综合题不先分清每问用什么方法 | 课件第 ⑤ 模块固定"找问题 → 选方法 → 算"的顺序，拖动人数时方法不变 |
| 把"小数的性质"当成"小数的读法" | 回到第四单元：性质只针对**末尾**的 0 |
| 用末位对齐算小数加减 | 回到第五单元第 ③ 模块：每一列计数单位必须相同 |
| 人数不同比总数 | 回到第六单元第 ③ 模块两种情境对比 |
| 试商不会调 | 回到第一单元第 ③ 模块四步：看作 → 试商 → 检验 → 调商 |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"11 题（知识网络、计算、读图）。
- **单元作业**：第三档"扩展思维"12 题（综合应用、易错辨析、思维提升）。
- **评价建议**：单元检测可把第三档改成"**说理题**"——
  给一个综合问题，要求学生先说"每问用什么方法"，再列式计算，
  重点评价**方法选择的合理性**。

## 九、四档分层与星级（2026-10 增补）

本单元的练习按**难度分四档，用星级标注**：

| 档位 | 星级 | 定位 | 用法 |
|---|---|---|---|
| 第一档 巩固基础 | ★★★ | 随堂练 | 课堂当堂完成，5 分钟 |
| 第二档 动手操作 | ★★★ | 读图 / 操作 | 课堂或课后，边做边学 |
| 第三档 扩展思维 | ★★★★ | 拓展题 | 单元作业主力 |
| 第四档 五星挑战 | ★★★★★ | 浅奥思维 | 选做，供学有余力的学生 |

**第四档题目的共同特征**：都需要**两步以上**的思考——
先从已知条件里"倒推"出中间量，再用本单元的规律求解；
或需要在两个结论之间做**辨析**（如"等腰三角形一个角是 40°，顶角是 100°"要分两种情况讨论）。

### 鼓励机制

学生**答对四星或五星题**时，页面会给出正反馈：
- **四星题**：「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：**「你好棒！」**横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 Web Audio 实时合成，**不引用任何外部音频文件**，
> 课件保持"单文件、零外部依赖、离线可用"。

**教学建议**：不要把"做对几道题"当成评价目标。
星级只是**难度标识**，真正的评价要看学生**能不能说清自己用了哪条规律、为什么这样想**。
五星题答错是正常的——它的价值恰恰在于让学生体验"想不出来"的过程，
教师可借此追问："你卡在哪一步？如果把这道题拆成两步，第一步你能做吗？"
