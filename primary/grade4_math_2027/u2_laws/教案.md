# 第二单元《混合运算和运算律》教学设计

> 人教版（2024 年审定）四年级数学下册 · 配套课件 `index.html`（7 个课时）

## 一、教材分析

本单元承接三年级"四则混合运算"，把"算得对"推进到"**算得巧**"。
两条腿：一是**运算顺序**（把混合运算的规则理清），二是**运算律**（用规律简化计算）。

难点在**运算律的迁移与自觉运用**：
学生最容易犯的错是"知道有简便方法，但说不出用了哪条规律"，
或者把运算律当成"新算法"凭空凑数。
因此课件把每一步变形都标注了**依据哪条规律**，并在分配律上用**面积模型**讲清道理，
而不只是给规则。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 掌握混合运算的顺序；理解并能运用加法交换律、结合律、乘法交换律、结合律、分配律；会进行简便计算 |
| 过程方法 | 在"观察—猜想—举例—归纳"中理解运算律；在面积模型中建立分配律的直观 |
| 情感态度 | 形成"先观察算式特点，再选择规律"的习惯；体会数学的简洁之美 |

## 三、教学重点与难点

- **重点**：混合运算的顺序；五大运算律的含义与应用。
- **难点**：**运算律的逆用**（把相同的因数提取出来，如 25×37+25×63）；
  **说清每一步变形依据哪条规律**；**简便计算不改变结果**。

## 四、教学准备

课件 `index.html`（投影）、方格纸（画面积模型）、彩色粉笔。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 混合运算的顺序 | ① 运算顺序 | 24+6×5、120÷3+18、(36+54)÷6、25×4÷5+18 四例分步演示 |
| 2 | 加法运算律 | ② 加法运算律 | 交换律、结合律、减法的性质 |
| 3 | 乘法运算律 | ③ 乘法运算律 | 点子图看交换律与结合律 |
| 4 | 乘法分配律 | ④ 乘法分配律 | 面积模型 + 正用逆用 |
| 5 | 简便计算（加减） | ⑤ 简便计算 | 99×25+25、101×36−36 |
| 6 | 简便计算（连乘） | ⑤ 简便计算 | 125×32×25 拆数凑整 |
| 7 | 整理与复习 | 练习区 | 三档练习 + 错题讲评 |

### 课堂节奏（以第 4 课时"乘法分配律"为例）

1. **情境（4 分钟）**：课件第 ④ 模块拖动滑块，把长方形切成两块，
   问"整块面积和两块面积之和一样吗？"——让学生**看见**等式成立。
2. **归纳（8 分钟）**：从面积模型抽象出字母式 **(a+b)×c = a×c+b×c**，
   追问"反过来读是什么？"引出**逆用**（课件第 ④b 模块第 ⑤ 步）。
3. **辨析（10 分钟）**：课件第 ④b 模块完整演示 102×45 与 25×37+25×63，
   让学生指出**每一步用了哪条规律**。强调：**拆开乘 / 合起来**两种方向。
4. **练习（10 分钟）**：第一档中分配律辨析题 + 第二档简便计算题当堂完成。
5. **小结（3 分钟）**：板书——**分配律能正用也能逆用；简便计算每步都要说清依据**。

## 六、板书设计

```
              混合运算和运算律
  运算顺序：① 有括号先算括号  ② 先乘除后加减  ③ 同级从左往右
  加法交换律：a + b = b + a
  加法结合律：(a + b) + c = a + (b + c)
  减法性质：a - b - c = a - (b + c)
  乘法交换律：a × b = b × a
  乘法结合律：(a × b) × c = a × (b × c)
  乘法分配律：(a + b) × c = a × c + b × c
              a × c + b × c = (a + b) × c   ← 逆用
  简便计算的依据：运算律（只改变顺序，不改变数和结果）
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 24+6×5 算成 150 | 课件第 ① 模块分步演示，先算乘法再算加法 |
| 同级运算从左往右记不清 | 课件第 ① 模块 25×4÷5+18 一例专门演示"同级从左往右" |
| 简便计算说不出用了哪条规律 | 课件第 ⑤ 模块每一步都标注依据的规律名称，要求学生复述 |
| 分配律只会正用（拆开）不会逆用（合起来） | 课件第 ④b 模块第 ⑤~⑦ 步专门演示逆用 |
| 简便计算时把数字算错了 | 强调"运算律只改变顺序，结果不变"，用原式验算 |
| 认为 25×37+25×63 不能简算 | 回到课件第 ④ 模块找"相同因数 25"这个特征 |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"11 题。
- **单元作业**：第三档"扩展思维"10 题（巧算、简便推理、易错辨析）。
- **评价建议**：要求学生在作业本上**写出每一步用了哪条运算律**，
  只写结果不给分的部分要扣分——这是本单元的关键评价点。

## 九、四档分层与星级（2026-10 增补）

本单元的练习按**难度分四档，用星级标注**：

| 档位 | 星级 | 定位 | 用法 |
|---|---|---|---|
| 第一档 巩固基础 | ★★★ | 随堂练 | 课堂当堂完成，5 分钟 |
| 第二档 动手操作 | ★★★ | 读图 / 操作 | 课堂或课后，边做边学 |
| 第三档 扩展思维 | ★★★★ | 拓展题 | 单元作业主力 |
| 第四档 五星挑战 | ★★★★★ | 浅奥思维 | 选做，供学有余力的学生 |

**第四档题目的共同特征**：都需要**两步以上**的思考——
先从已知条件里"倒推"出中间量，再用本单元的规律求解；
或需要在两个结论之间做**辨析**（如"等腰三角形一个角是 40°，顶角是 100°"要分两种情况讨论）。

### 鼓励机制

学生**答对四星或五星题**时，页面会给出正反馈：
- **四星题**：「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：**「你好棒！」**横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 Web Audio 实时合成，**不引用任何外部音频文件**，
> 课件保持"单文件、零外部依赖、离线可用"。

**教学建议**：不要把"做对几道题"当成评价目标。
星级只是**难度标识**，真正的评价要看学生**能不能说清自己用了哪条规律、为什么这样想**。
五星题答错是正常的——它的价值恰恰在于让学生体验"想不出来"的过程，
教师可借此追问："你卡在哪一步？如果把这道题拆成两步，第一步你能做吗？"
