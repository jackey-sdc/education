1混合运算的顺序

核心动画先算乘除，后算加减

点"下一步"，看一个算式按什么顺序算： ① 有括号，先算括号里面的 → ② 先算乘除，后算加减 → ③ 同一级运算，从左往右依次算。
教学口径：同级运算从左往右；有乘除又有加减，先算乘除。

2加法的运算律

动画交换律与结合律：数字换个位置，和不变

点"下一步"看等式变形： 加法交换律 a + b = b + a（两个数交换位置，和不变）； 加法结合律 (a + b) + c = a + (b + c)（三个数先算前两个或先算后两个，和不变）。
教学口径：运算律只改变运算顺序，不改变运算数和结果。

3乘法的运算律

动画点子图看懂交换律和结合律

拖动滑块改变每组个数，看总数不变： 乘法交换律 a × b = b × a（两个因数交换位置，积不变）； 乘法结合律 (a × b) × c = a × (b × c)（三个数先算前两个或先算后两个，积不变）。
教学口径：乘法交换律和结合律可以连用。

4乘法分配律

核心动画用面积模型理解 (a + b) × c = a × c + b × c

拖动滑块改变 a、b 的比例，看长方形怎样被切成两块： 整块面积 = (a + b) × c，两块面积之和 = a × c + b × c，两者相等。
教学口径：两个数的和与一个数相乘，可以分别用这个数去乘两个数，再把积相加。

—

动画分配律的逆用与变形

点"下一步"，看分配律怎么"拆"和"合"： 拆：102 × 45 = (100 + 2) × 45 = 4500 + 90； 合：25 × 37 + 25 × 63 = 25 × (37 + 63) = 25 × 100。
教学口径：乘法分配律可以正用，也可以逆用。

5简便计算

动画凑整：把数凑成整十整百

点"下一步"，看怎样把难算的式子变简单： 先交换，再结合，把能凑成整数的两个数放在一起算。
教学口径：简便计算的依据是运算律，不是"新算法"——每一步变形都要写清用了哪条规律。
