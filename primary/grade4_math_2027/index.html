① 课程结构（2027 春 · 人教版四下）

本册共 7 个单元（含 1 个综合实践）。下表是教材的官方单元顺序，与本仓库的课件一一对应。

单元内容课时本册地位
一除数是两位数的除法7数与代数：整数除法的算理与算法
二混合运算和运算律7数与代数：运算顺序与运算律（算得巧）

① 除数是两位数的除法 7 课时

口算除法 · 笔算除法 · 试商与调商 · 商的变化规律 · 解决问题

  • 想乘法算除法（小棒分组图）
  • 笔算除法竖式逐步演示（商写在各位正上方）
  • 试商与调商（把除数看作接近的整十数）
  • 商的变化规律（同时乘除同数，商不变）
  • 进一法与去尾法（租船 / 裁布 / 订餐）

③ 通用教学流程（每课时通用）

环节时间操作
情境导入3~5 分钟打开课件对应模块，用动画制造认知冲突（如"0.5 和 0.48 谁大""405÷15 试商几次"）
探究新知12~15 分钟逐步点"下一步"，让学生先猜后看；关键处暂停，让学生说出道理
巩固练习8~10 分钟第一档（巩固）当堂完成，答错只给提示、不给答案
动手操作5 分钟第二档（动手）投屏或学生机操作，验证操作过程
拓展提升作业第三档（扩展）作单元作业；答案在页面末尾，可自评
练习设计说明：每档题量固定、单独计分、可单独重做；答错给提示并指向对应的动画模块，答对才给解析；答案集中折叠在页面末尾，便于讲评与打印。

④ 全册易错点速查（讲评时可直接投屏）

单元高频错误纠正办法
一试商偏大/偏小后不会调；余数比除数大；商中间的 0 漏写；进一法与去尾法混用课件第 ③ 模块专练调商；第 ⑤ 模块两种情境对比，明确"剩下也要占一份"还是"不够一份不算"
二同级运算从左往右记不清；简便计算说不出用了哪条规律；分配律只会正用不会逆用课件第 ① 模块分步演示运算顺序；第 ④ 模块面积模型理解分配律
三认为"等边三角形不是等腰三角形"；钝角三角形"每个角都大于 90°"；把直角三角形的锐角都说成 45°课件第 ③ 模块末明确"等边是特殊的等腰"；锐角必须限定"等腰直角三角形"
四小数中间的 0 也去掉；整数部分的 0 也去掉；0.5 与 0.48 比错；小数点移动方向记反课件第 ④ 模块用数轴演示"点重合"与"点分开"；第 ⑤ 模块"右移扩大、左移缩小"
五列竖式末位对齐；得数小数点没对齐；减法退位忘了；混合运算先算加法课件第 ③ 模块专门对比"末位对齐"的错误列法，红色虚线标出小数点位置
六人数不同却只比总数；认为平均数一定是其中某个数；求平均数忘记先求总数课件第 ③ 模块两种情境并排对比；第 ② 模块"两步走"固定顺序
七综合题不先分清"每一问用什么方法"；平均数那一问忘了除以人数课件第 ⑤ 模块分步演示"先找问题 → 再选方法 → 最后算"

⑤ 评价建议

  • 过程性评价（60%）：动画课堂的观察记录 + 第一/二档练习的正确率与订正质量。
  • 单元检测（30%）：第三档"扩展思维"变身为 4~5 道的口头/书面答辩题。
  • 综合与实践（10%）："制定旅游计划"的方案与评估记录单。
  • 评价语言要指向思维过程（"你是怎么判断该用进一法还是去尾法的"），而不仅是"对/错"。
