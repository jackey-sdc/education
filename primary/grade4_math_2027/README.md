## 课件设计约定

- **四档分层 + 星级标注**：巩固基础（★★★ 随堂练）→ 动手操作（★★★）→
  扩展思维（★★★★ 拓展题）→ **五星挑战（★★★★★ 浅奥思维，两步以上思考）**，
  每档独立计分、可单独重做。
- **正反馈机制**：学生**答对四星或五星题**时——
  四星题弹出「答对啦！」+ 局部点赞 + 一声"叮"；
  五星题弹出**「你好棒！」+ 满屏点赞 + 喜悦琶音**；
  全部挑战题答对再触发一次「太棒了！」全屏庆祝。
  音效由 **Web Audio 实时合成**，不引任何外部文件，保持零依赖离线可用。
- **反馈策略**：答错只给**提示**并指回对应动画模块，**不泄露答案**；答对才给**解析**。
- **陷阱题**：把最高频错误做成干扰项（试商不会调、小数点末位对齐、
  去掉小数中间的 0、人数不同却比总数、等边三角形不是等腰三角形等）。
- **答案区**：集中折叠在页面末尾，便于讲评与打印；内置 `@media print` 样式，
  打印时隐藏导航与按钮。
- **口径先行**：每单元的"一句话规则"在动画、题干、解析、教案中**同源一致**，
  验收脚本会逐单元核对关键口径词。

## 语音 + 动画讲解（每个动画模块都有一节）

每个动画模块标题下的「讲解」卡片，是本册新增的**语音＋动画同步讲解**：
点「▶ 开始讲解」后，画面按 **六拍骨架** 逐拍推进，同时播朗读；
空格暂停、Esc 停止、点任意一拍可单拍重讲。

**六拍骨架**：读信息 → 提问 → 找关系 → 算一算 → 检验 → 迁移。
一拍 = 一条字幕（板书用）＋ 一个绝对状态动画 ＋ 一句朗读。

- **动作为主**：每拍调用 `window.MOD.<模块>.set(...)` 把画面**直接设成某个状态**，
  不依赖"再点几下"；改 `window.MOD.<模块>.set(4)` 就跳到第 5 拍的状态。
- **语音预生成并内联**：`tools/tts_build.py` 合成 m4a＋`manifest.json`，
  `build.py` 把音频打成 base64 内联进 `index.html`（`window.NARR_AUDIO`），
  仍是**单文件、零外部依赖、离线可用**；查不到音频时自动回退浏览器 `speechSynthesis`。
- **自然度三杠杆**：① 文案口语化（有设问、有指代、句子短）→
  ② 断句留白＋要点重读（逗号 300ms / 句号 620ms；重读片段降速 26%）→
  ③ 神经语音（Edge TTS `zh-CN-XiaoxiaoNeural`，rate −10%，64kbps 单声道 AAC）。
- **分镜自检**：每单元的 `narr.js` 必须过三道闸——
  `check_explain.py`（剧本+跳拍+画面推进+报错）、
  `check_audio_play.py`（音频真在播、播完自动推进、暂停有效）、
  `check_pron.py`（回读数字，确认"30"念成三十而不是三零）。
- **三轮评审留痕**：每单元 `iterations.md` 记录三轮评审中被推翻的设计，
  每轮至少推翻一处，且结论落到代码。

```bash
# 改文案后重新合成语音（带缓存，只重录改动的那几条）
python3 tools/tts_build.py u7_review
python3 build.py u7_review
python3 tools/check_pron.py u7_review      # 回读校验数字
python3 tools/check_audio_play.py u7_review
python3 tools/make_audition.py             # 汇总成试听页 audition.html
```

## 页面结构：左侧章节栏 + 右侧内容

所有课件页（总览页 + 7 个单元页）统一为：

- **左侧章节栏**：列出本单元的各个动画模块、"分层练习""答案与解析"，以及"上一单元 / 下一单元 / 回到课程总览"；
  滚动时左栏会**自动高亮当前所在章节**。
- **右侧内容区**：教学动画与练习。
- **左栏可点击隐藏**：点右上角 **☰ 章节栏** 收起（内容区随即铺满整屏，便于投影）；
  收起后左边缘会出现一条竖排 **章节栏** 把手，点它即可展开。
  状态记在 `localStorage`，刷新后保持；快捷键 `Ctrl/⌘ + [` 也可切换。
- 窄屏（≤940px）自动变成**抽屉式**：点 ☰ 从左侧滑出，点遮罩或按 Esc 关闭。

## 使用方式

1. **教师演示**：打开 `index.html` → 进入某个单元 → 用左栏切换模块 → 全屏（F11）。
2. **学生练习**：把单元的 `index.html` 发到学生电脑，学生作答后展开答案自评。
3. **打印讲评**：展开"答案与解析" → Ctrl/Cmd+P（打印样式已内置）。

## 源码与重建

单元课件是**构建产物**。修改流程：

```bash
cd primary/grade4_math_2027

# 1. 改共享样式 / 引擎
vim assets/style.css assets/engine.js

# 2. 改某个单元的内容与逻辑
vim u1_divide/body.html u1_divide/app.js

# 3. 重新构建（全部或单个单元）
python3 build.py              # 构建全部
python3 build.py u1_divide    # 只构建指定单元

# 4. 验收
python3 tests/audit.py                 # 四层验收（结构/内容/交互/视觉），对全部单元
python3 tests/audit.py u1_divide       # 只查一个单元
python3 tests/test_answers.py          # 回填标准答案，验证题答自洽
python3 tests/check_answers.py         # 选择题答案独立复算（防下标写错）
python3 u1_divide/tests/test_unit.py   # 该单元的几何断言 + 交互巡检

# 5. 预览图
python3 tests/make_preview.py
```

> ⚠️ 改了 `assets/` 后必须**重新构建全部单元**——单元页是把引擎内联进去的单文件。
