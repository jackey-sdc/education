# 第五单元《小数的加法和减法》教学设计

> 人教版（2024 年审定）四年级数学下册 · 配套课件 `index.html`（5 个课时）

## 一、教材分析

本单元是小数学习的**收口单元**：前面学了小数的意义与数位，
本单元要把"小数的意义"真正用起来——**为什么小数点要对齐**。

这是本册**最典型的易错单元**。学生的错误极其集中：
**列竖式时末位对齐**。为什么错？因为整数竖式里末位就是个位，
对齐末位似乎"总没错"；但小数里末位可能是千分位，**计数单位根本不同**。

课件因此专门设计了一个模块，把"末位对齐"和"小数点对齐"
两种列法并排画出来，用**数位与计数单位的对应关系**讲清道理，
而不是简单说"要对齐小数点"。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 掌握小数加减法的笔算方法；会进行小数加减混合运算；会把整数运算律推广到小数 |
| 过程方法 | 在比较两种列法中理解小数点对齐的道理；经历"补 0—退位—对齐"的算理过程 |
| 情感态度 | 形成"数位对齐才能算"的数学本质认识；养成列式后先检查小数点的习惯 |

## 三、教学重点与难点

- **重点**：小数加减法的笔算（小数点对齐、相同数位相加减、得数小数点对齐）。
- **难点**：**小数点对齐的算理**（不是规则，是道理）；
  **位数不同时补 0**；**退位**（不够减向前一位借 1 当 10）；
  **得数末尾的 0 可以去掉**。

## 四、教学准备

课件 `index.html`（投影）、竖格本（关键：格子要宽，便于对齐小数点）。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 小数加法 | ① 小数加法 | 3.2+2.8、12.5+7.35：进位与小数点对齐 |
| 2 | 小数减法 | ② 小数减法 | 20−0.35、5−3.68：补 0 与退位 |
| 3 | 小数点对齐（易错辨析） | ③ 小数点对齐 | 末位对齐 vs 小数点对齐并排对比 |
| 4 | 小数加减混合运算 | ④ 小数加减混合运算 | 3.6+0.4×2.5 等四例 |
| 5 | 运算律推广到小数 + 整理 | ⑤ 运算律推广到小数 | 0.7+3.9+0.3、2.5×1.3×4 |

### 课堂节奏（以第 3 课时"小数点对齐"为例）

1. **暴露错误（6 分钟）**：课件第 ③ 模块第 ① 步，故意按**末位对齐**列 1.2+0.68，
   让学生算。算出来是 **1.80**。
2. **制造冲突（4 分钟）**：同一个算式，正确列法（1.20+0.68）得 **1.88**。
   **两个结果不一样！**（课件第 ③ 模块第 ② 步）
3. **追问道理（10 分钟）**：课件第 ③ 模块对比两种列法，
   引导学生发现：**列竖式时每一列代表的计数单位必须相同**。
   末位对齐时，"2"的单位是 0.1，"8"的单位是 0.01，**根本不能直接相加**。
4. **归纳（6 分钟）**：板书——**小数加减法必须小数点对齐（相同数位对齐）**。
   课件第 ③ 模块第 ③ 步用"检验"收尾：0.68 + 1.88 = 2.56 = 1.2 + 0.68 ✓。
5. **练习（8 分钟）**：第二档中竖式计算题当堂完成，**重点检查小数点位置**。
6. **小结（3 分钟）**：强调**算完还要看得数的小数点有没有对齐**。

## 六、板书设计

```
                  小数的加法和减法
  笔算口诀：小数点对齐（相同数位对齐）→ 相同数位相加减 → 得数小数点对齐
  道理：每一列的计数单位必须相同，才能直接加减
        （末位对齐时 0.1 与 0.01 相加是错的）
  位数不同：位数少的补 0（20 → 20.00）
  退位：哪一位不够减，就从前一位退 1 当 10
  得数：末尾的 0 可以去掉（1.50 = 1.5）
  混合运算：有括号先算括号；没有括号先乘除后加减；同级从左往右
  运算律推广：整数运算律对小数同样适用
              （0.7+3.9+0.3 = (0.7+0.3)+3.9 = 4.9）
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 列竖式末位对齐 | 课件第 ③ 模块专门对比两种列法；用"每一列计数单位相同"讲清道理 |
| 位数不同不对齐（20 − 0.35 直接列） | 课件第 ② 模块第 ② 步演示"20 看成 20.00" |
| 减法忘记退位 | 课件第 ② 模块检验环节强调"不够减向前一位退 1 当 10" |
| 得数小数点没对齐 | 课件第 ① ② 模块第 ④ 步专门标出"得数的小数点要和上面的小数点对齐" |
| 混合运算先算加法（3.6+0.4×2.5 先算 3.6+0.4） | 课件第 ④ 模块分步演示运算顺序 |
| 简便计算时把 0.7+0.3 算错 | 课件第 ⑤ 模块每步标注运算律，要求口算准确 |
| 误以为得数末尾的 0 不能去掉 | 用第四单元"小数的性质"回扣：1.50 = 1.5 |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"12 题（竖式计算、混合运算）。
- **单元作业**：第三档"扩展思维"11 题（简便计算、巧算、易错辨析）。
- **评价建议**：竖式题**只批小数点位置**，其余正确即可给分——
  本单元的核心就是位置意识。

## 九、四档分层与星级（2026-10 增补）

本单元的练习按**难度分四档，用星级标注**：

| 档位 | 星级 | 定位 | 用法 |
|---|---|---|---|
| 第一档 巩固基础 | ★★★ | 随堂练 | 课堂当堂完成，5 分钟 |
| 第二档 动手操作 | ★★★ | 读图 / 操作 | 课堂或课后，边做边学 |
| 第三档 扩展思维 | ★★★★ | 拓展题 | 单元作业主力 |
| 第四档 五星挑战 | ★★★★★ | 浅奥思维 | 选做，供学有余力的学生 |

**第四档题目的共同特征**：都需要**两步以上**的思考——
先从已知条件里"倒推"出中间量，再用本单元的规律求解；
或需要在两个结论之间做**辨析**（如"等腰三角形一个角是 40°，顶角是 100°"要分两种情况讨论）。

### 鼓励机制

学生**答对四星或五星题**时，页面会给出正反馈：
- **四星题**：「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：**「你好棒！」**横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 Web Audio 实时合成，**不引用任何外部音频文件**，
> 课件保持"单文件、零外部依赖、离线可用"。

**教学建议**：不要把"做对几道题"当成评价目标。
星级只是**难度标识**，真正的评价要看学生**能不能说清自己用了哪条规律、为什么这样想**。
五星题答错是正常的——它的价值恰恰在于让学生体验"想不出来"的过程，
教师可借此追问："你卡在哪一步？如果把这道题拆成两步，第一步你能做吗？"
