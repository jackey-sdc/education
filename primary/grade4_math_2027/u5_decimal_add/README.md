# 小数的加法和减法 · 动画课件

> 人教版（2024 年审定）四年级数学下册 · 小数加减法笔算 / 小数点对齐 / 混合运算 / 运算律推广到小数

配套课件：`index.html`（单文件、零外部依赖、离线可用，双击即开）　配套教案：`教案.md`

## 一、这个单元学什么

小数加减法笔算 / 小数点对齐 / 混合运算 / 运算律推广到小数

**5 个课时**　共 **36 题**（巩固 14 题 + 动手 12 题 + 扩展 10 题）。

## 二、课件结构

左侧为章节栏（可点击隐藏，隐藏后内容铺满投影），右侧为内容区。

| 章节 | 内容 |
|---|---|
| #s-add | ① 小数加法 |
| #s-sub | ② 小数减法 |
| #s-align | ③ 小数点对齐（易错） |
| #s-mixed | ④ 小数加减混合运算 |
| #s-law | ⑤ 运算律推广到小数 |
| #quiz | 分层练习 |
| #answers | 答案解析 |

## 三、动画模块

| 模块 | 教学作用 |
|---|---|
| ① 小数加法 | 竖式计算，红色虚线标出小数点 |
| ② 小数减法 | 位数不同补 0，不够减向前一位退 1 当 10 |
| ③ 小数点对齐（高频易错） | 末位对齐 vs 小数点对齐并排对比 |
| ④ 小数加减混合运算 | 有括号先算括号；先乘除后加减；同级从左往右 |
| ⑤ 运算律推广到小数 | 0.7+3.9+0.3、2.5×1.3×4 等凑整 |

## 四、四档分层练习（星级）

| 档位 | 星级 | 名称 | 题量 |
|---|---|---|---|
| 第一档 | ★★★ | 巩固基础 | 14 题 |
| 第二档 | ★★★ | 动手操作 | 12 题 |
| 第三档 | ★★★★ | 扩展思维 | 10 题 |
| 第四档 | ★★★★★ | 五星挑战 · 浅奥思维 | 12 题 |

- 四档**独立计分、独立重做**（不刷新整页）。
- **答错只给提示**（指回对应的动画模块），**不泄露答案**；**答对才给解析**。
- 答案与解析集中在页面末尾的折叠区，讲评时展开，或直接 Ctrl/Cmd+P 打印。

### 星级与鼓励机制

| 星级 | 对应档位 | 定位 |
|---|---|---|
| ★★★ | 第一档 巩固基础 | 随堂练，课堂当堂完成 |
| ★★★ | 第二档 动手操作 | 读图 / 操作，边做边学 |
| ★★★★ | 第三档 扩展思维 | 拓展题，课后作业主力 |
| ★★★★★ | 第四档 五星挑战 | 浅奥思维，两步以上思考，供学有余力的学生选做 |

**答对四星或五星题时**，页面会给出正反馈：
- **四星题**：中央弹出「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：中央弹出「**你好棒！**」横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**（C-E-G-C）；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 **Web Audio 实时合成**，不引用任何外部音频文件——
> 课件依然是**单文件、零外部依赖、离线可用**。
> 页面尊重系统的「减弱动态效果」设置（`prefers-reduced-motion`），此时不播放动画。

## 五、怎么用

1. **教师演示**：打开 `index.html` → 左栏切模块 → 全屏（F11）投影。
2. **学生练习**：把 `index.html` 发到学生电脑，学生作答后展开答案自评。
3. **打印讲评**：展开"答案与解析" → Ctrl/Cmd+P（内置 `@media print`，隐藏导航与按钮）。

## 六、源码与重建

本课件是**构建产物**，源码是本目录下的三个文件：

```
u5_decimal_add/
├── meta.json    # 元数据：标题 / 导航 / 三档练习 / 上下单元
├── body.html    # 内容骨架（含 <!--QUIZ--> <!--ANSWERS--> 占位符）
├── app.js       # 数据 + 渲染逻辑 + bootCourse(...)
└── index.html   # ⚙️ 构建产物（由 build.py 生成）
```

```bash
cd primary/grade4_math_2027
python3 build.py u5_decimal_add      # 只重建本单元
python3 tests/audit.py u5_decimal_add       # 四层验收（结构/内容/交互/视觉）
python3 u5_decimal_add/tests/test_unit.py   # 本单元几何断言 + 交互巡检
```
