> 依据 `math-courseware-explainer` skill 的强制流程：每节讲解脚本必须经过三轮评审
> （① 需求是否清晰 ② 场景设计是否合理 ③ 通俗易懂且体现数学思维培养），
> 每轮必须**至少推翻一处**原设计，推翻结论落到代码。

本单元 5 节 × 6 拍 = 30 拍。以下按节记录三轮评审中被推翻的地方。

## 一、小数加法（#s-add）

**第一轮｜需求是否清晰**
初稿把「对齐、计算、进位、化简」四步平均分给四拍。
→ 推翻：加法的难点只有一处——**为什么必须对齐**，其余是熟练度。
主线改为「先把数对齐 → 再问凭什么这样对齐 → 算 → 化简」。

**第二轮｜场景设计是否合理**
原设计只在竖式上加高亮，`ACAP` 说明行没有，六拍里有多拍文字一致。
→ 推翻：每拍必须在竖式下方写一句**当前这一步的判断依据**（`ACAP[]`），
如"十分位 8+5=13，写 3 进 1"。画面靠文字推进，不靠颜色。

**第三轮｜通俗易懂 + 数学思维**
「小数点对齐」被当成格式要求。
→ 推翻：要讲清它**保证的是同一数位相加**。
迁移拍用"3.5 元 + 2.75 元"这种钱的例子，让对齐变成"元加元、角加角"。

---

## 二、小数减法（#s-sub）

**第一轮｜需求是否清晰**
初稿把减法讲成加法的镜像。
→ 推翻：减法多两个坑——**位数不同要补 0**、**退位跨整数部分**。
主线改为「先补齐 → 再逐位减 → 遇退位要标 → 得数化简」。

**第二轮｜场景设计是否合理**
原设计用的例子位数相同，补 0 这一步根本没有出现。
→ 推翻：主例必须位数不同（20 − 0.35），并在竖式上把补出的 0 用**浅色虚线**显示，
让孩子看见"补出来的 0 也是数"。同时加 `SCAP[]` 逐拍说明。

**第三轮｜通俗易懂 + 数学思维**
「退位」讲成操作。
→ 推翻：要让孩子看到**退 1 当 10** 的过程（在借位处标 −1 与 +10），
把退位从"划一下"变成"换零钱"，这是位值制的核心经验。

---

## 三、小数点对齐（高频易错）（#s-align）

**第一轮｜需求是否清晰**
初稿把本节写成"对齐 vs 末位对齐哪个对"的判断题。
→ 推翻：判断题只到"知道"，没到"看懂"。
主线改为「先看错误列法 → 找出错在哪 → 用单位解释 → 得出正确列法」。

**第二轮｜场景设计是否合理**
（本轮为自检后修正）
① `MOD.align` 最初被误插进 `initAdd` 里，`#s-align` 根本没拿到控制器，
闸①判「画面推进：1 个不同画面」。
→ 推翻：控制器必须建在**自己的模块作用域**里（移入 `initAlign` 末尾）。
② 三态（末位对齐 / 小数点对齐 / 正确结论）撑不满六拍，后段必然撞画面。
→ 推翻：新增第 4 态「错在哪：单位不同」——在 2 与 8 上画红圈，
分别标「2 的单位是 0.1」「8 的单位是 0.01」，
note 写「不同单位的数不能直接相加减」。
修正后画面推进 4 个以上，闸①全绿。

**第三轮｜通俗易懂 + 数学思维**
"末位对齐是错的"只是被告知。
→ 推翻：必须给出**后果**——按末位对齐算 3.5 + 2.75，
十位上的数加到了百分位上，结果差了一个数量级。
把"错"变成"差多少"，孩子才会真的改。

## 四、小数加减混合运算（#s-mixed）

**第一轮｜需求是否清晰**
初稿把混合运算讲成"按顺序算"。
→ 推翻：顺序规则已在第二单元学过，本节新东西是**小数点在混合运算里怎么跟**。
主线改为「先定顺序 → 每一步都把小数点对齐 → 结果检查位数」。

**第二轮｜场景设计是否合理**
原设计只有一道算式，看不出顺序的影响。
→ 推翻：必须用**同一组数、两种顺序**对照（3.6 + 0.4 × 2.5），
让 4.6 与 10 两个结果同时出现，顺序的重要性立刻显形。

**第三轮｜通俗易懂 + 数学思维**
「先乘除后加减」被当规定。
→ 推翻：要给**情境解释**——买东西先算单价×数量，再加总，
生活里本来就是先乘后加。规则从情境里长出来，才不会被忘。

---

## 五、运算律推广到小数（#s-law）

**第一轮｜需求是否清晰**
初稿只讲"整数运算律对小数也适用"。
→ 推翻：结论一句就完，撑不起一节。主线改为
「整数里为什么成立 → 换成小数还成立吗 → 验算一次 → 用它算得巧」。

**第二轮｜场景设计是否合理**
原设计直接给 0.25 × 4 = 1 这类"好看"的数。
→ 推翻：先给一组**不好看的数**（如 0.3 × 7 + 0.7 × 7）验证规律成立，
再给能凑整的例子。顺序反了就成了"专门挑好的数骗人"。

**第三轮｜通俗易懂 + 数学思维**
没有解释"为什么小数也可以"。
→ 推翻：迁移拍讲清**依据**——运算律说的是"几个数怎么合起来"，与数是不是小数无关；
小数只是把 1 分小了，合起来的规则不变。这是"数系扩充后规律保持"的第一次体验。
