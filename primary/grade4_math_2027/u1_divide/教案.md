# 第一单元《除数是两位数的除法》教学设计

> 人教版（2024 年审定）四年级数学下册 · 配套课件 `index.html`（7 个课时）

## 一、教材分析

本单元是整数除法的主线单元，承接三年级"有余数的除法"与四年级上册"多位数乘两位数"，
核心是**除数是两位数的笔算除法**。

本单元的难点不在"会算"，而在**算理**：
为什么先看前两位、为什么商要写在对应数位的上方、试商偏了怎么调。
因此课件把竖式做成可分步演示的动画，并专门设计"试商与调商"模块，
把最高频的错误（商大了不会调、只会调商不会检验）做成可视化的对比。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 掌握口算除法、笔算除法（除数是两位数）；理解试商与调商；理解商的变化规律；会用进一法与去尾法解决问题 |
| 过程方法 | 经历"想乘法算除法 → 竖式四步 → 试商检验 → 调商"的过程；在比较中归纳商的变化规律 |
| 情感态度 | 养成"算完必须检验"的习惯；感受算法背后的道理而不是机械模仿 |

## 三、教学重点与难点

- **重点**：笔算除法的算理（从高位除起、除到哪一位商写哪一位）；试商与调商。
- **难点**：**试商后判断商偏大还是偏小**（乘积比被除数大→商大了要调小；商小要调大）；
  **商中间或末尾有 0 的写法**；**进一法与去尾法的选择**。

## 四、教学准备

课件 `index.html`（投影）、小棒（每捆 10 根）、计算器（仅用于检验）。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 口算除法（整十数÷整十数） | ① 口算除法 | 小棒图：60 根分给 2 组 → 想乘法算除法 |
| 2 | 口算除法（几百几十÷几十） | ①b 口算除法 | 先看末尾 0 的个数，再同时去掉 |
| 3 | 笔算除法（除数接近整十数） | ② 笔算除法 | 竖式四步：看 → 试 → 乘 → 减 → 落一位 |
| 4 | 试商与调商 | ③ 试商与调商 | 405÷15：试 3 → 60>40 → 调小为 2 |
| 5 | 商中间或末尾有 0 | ② 笔算除法 | 840÷28（末尾 0）、2415÷23（中间 0） |
| 6 | 商的变化规律 | ④ 商的变化规律 | 240÷16=15；同时乘除同数，商不变 |
| 7 | 解决问题（进一法/去尾法） | ⑤ 解决问题 | 租船（进一）vs 裁布（去尾） |

### 课堂节奏（以第 4 课时"试商与调商"为例）

1. **回顾（3 分钟）**：课件第 ② 模块，演示 425÷25 的竖式，追问"商 1 为什么写在十位上面"。
2. **制造冲突（6 分钟）**：出示 405÷15，让学生用课件第 ③ 模块试商。
   让学生先猜"把 15 看作几"——引出**看作接近的整十数**。
3. **探究调商（10 分钟）**：课件第 ③ 模块点"下一步"，检验 20×3=60 比 40 大，
   引导学生说出**"商大了要调小"**；再问"调成几？调完还要看什么？"
   （→ 调 1 格、再检验余数是否比除数小）。
4. **辨析易错（8 分钟）**：对比 405÷15（调小）与 828÷27（调大），
   让学生发现**商大了调小、商小了调大**这一对规则。
5. **练习（8 分钟）**：第一档 + 第二档中"试商调商"部分当堂完成。
6. **小结（3 分钟）**：板书口诀——**看作整十数，试商再检验；商大了调小，商小了调大，每次只调 1**。

## 六、板书设计

```
              除数是两位数的除法
  口算：想乘法算除法（几百几十÷几十：先看末尾 0 的个数）
  笔算四步：① 从高位除起，先看前两位（不够看前三位）
            ② 试商（把除数看作接近的整十数）
            ③ 乘 ④ 减（余数必须比除数小）
            ⑤ 落下一位，继续除
  竖式规矩：除到哪一位，商就写在那一位上面
  调商口诀：商大了调小，商小了调大，每次只调 1
  商的变化规律：被除数和除数同时乘或除以相同的数（0 除外），商不变
  解决问题：进一法（商+1）｜去尾法（舍去余数）
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 商写错数位（写成除到的那一位左边） | 课件第 ② 模块中商紧贴被除数各位正上方，高亮圈标出当前步；反复强调"除到哪一位写哪一位" |
| 试商偏大不会调 / 调后不检验 | 课件第 ③ 模块固定四步：看作 → 试商 → 检验乘积 → 调商得结论；调完必须看余数 < 除数 |
| 商中间的 0 漏写 | 用 2415÷23 这类题；商的每一位都要写，0 也要写 |
| 余数比除数大 | 每步结束检验"余数 < 除数"，课件第 ③ 模块检验环节 |
| 进一法与去尾法混淆 | 课件第 ⑤ 模块两种情境并排：租船（剩 1 人也要船）与裁布（剩 1 米不够做一件） |
| 几百几十除以几十时单位错 | 课件第 ①b 模块第 ② 步特别提示"去掉 0 后单位变了" |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"12 题（读竖式、调商、进一法去尾法）。
- **单元作业**：第三档"扩展思维"11 题（商的变化规律应用、推理、易错辨析）。
- **评价建议**：允许二次尝试，第一次错不扣分；关注学生能否**说清"商大了调小"的道理**，
  而不只是记住口诀。

## 九、四档分层与星级（2026-10 增补）

本单元的练习按**难度分四档，用星级标注**：

| 档位 | 星级 | 定位 | 用法 |
|---|---|---|---|
| 第一档 巩固基础 | ★★★ | 随堂练 | 课堂当堂完成，5 分钟 |
| 第二档 动手操作 | ★★★ | 读图 / 操作 | 课堂或课后，边做边学 |
| 第三档 扩展思维 | ★★★★ | 拓展题 | 单元作业主力 |
| 第四档 五星挑战 | ★★★★★ | 浅奥思维 | 选做，供学有余力的学生 |

**第四档题目的共同特征**：都需要**两步以上**的思考——
先从已知条件里"倒推"出中间量，再用本单元的规律求解；
或需要在两个结论之间做**辨析**（如"等腰三角形一个角是 40°，顶角是 100°"要分两种情况讨论）。

### 鼓励机制

学生**答对四星或五星题**时，页面会给出正反馈：
- **四星题**：「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：**「你好棒！」**横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 Web Audio 实时合成，**不引用任何外部音频文件**，
> 课件保持"单文件、零外部依赖、离线可用"。

**教学建议**：不要把"做对几道题"当成评价目标。
星级只是**难度标识**，真正的评价要看学生**能不能说清自己用了哪条规律、为什么这样想**。
五星题答错是正常的——它的价值恰恰在于让学生体验"想不出来"的过程，
教师可借此追问："你卡在哪一步？如果把这道题拆成两步，第一步你能做吗？"
