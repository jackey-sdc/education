# 除数是两位数的除法 · 动画课件

> 人教版（2024 年审定）四年级数学下册 · 口算除法 / 笔算除法 / 试商与调商 / 商的变化规律 / 解决问题

配套课件：`index.html`（单文件、零外部依赖、离线可用，双击即开）　配套教案：`教案.md`

## 一、这个单元学什么

口算除法 / 笔算除法 / 试商与调商 / 商的变化规律 / 解决问题

**7 个课时**　共 **35 题**（巩固 14 题 + 动手 11 题 + 扩展 10 题）。

## 二、课件结构

左侧为章节栏（可点击隐藏，隐藏后内容铺满投影），右侧为内容区。

| 章节 | 内容 |
|---|---|
| #s-oral | ① 口算除法 |
| #s-vertical | ② 笔算除法 |
| #s-trial | ③ 试商与调商 |
| #s-rule | ④ 商的变化规律 |
| #s-solve | ⑤ 解决问题 |
| #quiz | 分层练习 |
| #answers | 答案解析 |

## 三、动画模块

| 模块 | 教学作用 |
|---|---|
| ① 口算除法 | 想乘法算除法（小棒分组图 + 算式推导） |
| ①b 口算除法（二） | 几百几十除以几十：先看末尾 0 的个数，再同时去掉 |
| ② 笔算除法 | 除数是两位数的竖式逐步演示（商写在被除数各位正上方） |
| ③ 试商与调商 | 把除数看作接近的整十数 → 试商 → 检验乘积 → 调商 |
| ④ 商的变化规律 | 被除数和除数同时乘或除以相同的数，商不变 |
| ⑤ 解决问题 | 进一法（租船/订餐）与去尾法（裁布/装盒） |

## 四、四档分层练习（星级）

| 档位 | 星级 | 名称 | 题量 |
|---|---|---|---|
| 第一档 | ★★★ | 巩固基础 | 14 题 |
| 第二档 | ★★★ | 动手操作 | 11 题 |
| 第三档 | ★★★★ | 扩展思维 | 10 题 |
| 第四档 | ★★★★★ | 五星挑战 · 浅奥思维 | 12 题 |

- 四档**独立计分、独立重做**（不刷新整页）。
- **答错只给提示**（指回对应的动画模块），**不泄露答案**；**答对才给解析**。
- 答案与解析集中在页面末尾的折叠区，讲评时展开，或直接 Ctrl/Cmd+P 打印。

### 星级与鼓励机制

| 星级 | 对应档位 | 定位 |
|---|---|---|
| ★★★ | 第一档 巩固基础 | 随堂练，课堂当堂完成 |
| ★★★ | 第二档 动手操作 | 读图 / 操作，边做边学 |
| ★★★★ | 第三档 扩展思维 | 拓展题，课后作业主力 |
| ★★★★★ | 第四档 五星挑战 | 浅奥思维，两步以上思考，供学有余力的学生选做 |

**答对四星或五星题时**，页面会给出正反馈：
- **四星题**：中央弹出「答对啦！」横幅 + 局部点赞 + 一声清脆的"叮"；
- **五星题**：中央弹出「**你好棒！**」横幅 + **满屏点赞**飞过 + 一段**喜悦的琶音**（C-E-G-C）；
- **所有四星/五星题全部答对**：额外触发一次「**太棒了！**」全屏庆祝。

> 音效由 **Web Audio 实时合成**，不引用任何外部音频文件——
> 课件依然是**单文件、零外部依赖、离线可用**。
> 页面尊重系统的「减弱动态效果」设置（`prefers-reduced-motion`），此时不播放动画。

## 五、怎么用

1. **教师演示**：打开 `index.html` → 左栏切模块 → 全屏（F11）投影。
2. **学生练习**：把 `index.html` 发到学生电脑，学生作答后展开答案自评。
3. **打印讲评**：展开"答案与解析" → Ctrl/Cmd+P（内置 `@media print`，隐藏导航与按钮）。

## 六、源码与重建

本课件是**构建产物**，源码是本目录下的三个文件：

```
u1_divide/
├── meta.json    # 元数据：标题 / 导航 / 三档练习 / 上下单元
├── body.html    # 内容骨架（含 <!--QUIZ--> <!--ANSWERS--> 占位符）
├── app.js       # 数据 + 渲染逻辑 + bootCourse(...)
└── index.html   # ⚙️ 构建产物（由 build.py 生成）
```

```bash
cd primary/grade4_math_2027
python3 build.py u1_divide      # 只重建本单元
python3 tests/audit.py u1_divide       # 四层验收（结构/内容/交互/视觉）
python3 u1_divide/tests/test_unit.py   # 本单元几何断言 + 交互巡检
```
