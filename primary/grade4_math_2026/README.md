# 人教版四年级数学上册 · 动画课件（2026 秋）

依据**人教版（2024 年审定）四年级数学上册**教材，为 2026 年秋季学期整理的整套
"**课程大纲 + 动画课件 + 分层练习**"。全部课件为**单文件、零依赖、离线可用**，
双击 `index.html` 即可在教室电脑上直接上课。

## 课件设计约定

- **三层练习**：巩固基础（概念过关）→ 动手操作（读图/操作）→ 扩展思维（推理迁移），
  每档独立计分、可单独重做。
- **反馈策略**：答错只给**提示**并指回对应动画模块，**不泄露答案**；答对才给**解析**。
- **陷阱题**：把最高频错误做成干扰项（115° 读成 65°、改写与近似数混淆、
  纵轴刻度不足导致直条出格、鸡兔同笼不检验等）。
- **答案区**：集中折叠在页面末尾，便于讲评与打印；内置 `@media print` 样式，
  打印时隐藏导航与按钮。

## 页面结构：左侧章节栏 + 右侧内容

所有课件页（总览页 + 7 个单元页）统一为：

- **左侧章节栏**：列出本单元的各个动画模块、"分层练习""答案与解析"，以及"上一单元 / 下一单元 / 回到课程总览"；
  滚动时左栏会**自动高亮当前所在章节**。
- **右侧内容区**：教学动画与练习。
- **左栏可点击隐藏**：点右上角 **☰ 章节栏** 收起（内容区随即铺满整屏，便于投影）；
  收起后左边缘会出现一条竖排 **章节栏** 把手，点它即可展开。
  状态记在 `localStorage`，刷新后保持；快捷键 `Ctrl/⌘ + [` 也可切换。
- 窄屏（≤940px）自动变成**抽屉式**：点 ☰ 从左侧滑出，点遮罩或按 Esc 关闭。
- 左栏底部的**去向链接会看场合**：
  - 课件被**单独打开**时 → 显示「← 返回教育实验平台首页」（路径已修正为 `../../index.html`）；
  - 课件被**嵌在平台的 iframe 里**时 → 这条链接没有意义（平台就在外层），自动换成
    「↗ 在新窗口打开本课件」，老师可以直接把课件拽出来全屏投影。

## 使用方式

1. **教师演示**：打开 `index.html` → 进入某个单元 → 用左栏切换模块 → 全屏（F11）。
2. **学生练习**：把单元的 `index.html` 发到学生电脑（或局域网共享），学生作答后展开答案自评。
3. **打印讲评**：展开"答案与解析" → Ctrl/Cmd+P（打印样式已内置）。

## 源码与重建

单元课件是**构建产物**。修改流程：

```bash
# 1. 改共享样式 / 引擎
vim assets/style.css assets/engine.js

# 2. 改某个单元的内容与逻辑
vim u1_big_number/body.html u1_big_number/app.js

# 3. 重新构建（全部或单个单元）
python3 build.py              # 构建全部
python3 build.py u1_big_number # 只构建一个

# 4. 回归测试
python3 tests/test_answers.py            # 答案自洽性
python3 u1_big_number/tests/test_unit.py # 单元巡检

# 5. 重新生成预览图
python3 tests/make_preview.py
```

### 绘图约定（改动画前必读）

- 角度一律用**数学正方向（逆时针）为正**，坐标换算统一走 `polar()`（SVG 的 y 轴向下，需翻 y）。
- 圆弧统一走 `arcPoints()`，`sweep` 固定 0，不要手写 `A` 命令；起止角满足 `end = start + span`。
- 画角统一走 `drawAngle()`（自动处理"走短弧"，避免弧线绕远路）。
- 数据用数组描述，渲染函数**全量重绘**，不做增量更新。
- 圆周数字沿切向排版并加白色描边光晕（`haloText`），避免被射线压住。

## 自检（可选）

```bash
pip install playwright && playwright install chromium

python3 tests/audit.py            # ★ 四层验收：结构 / 内容 / 交互 / 视觉（全部单元）
python3 tests/audit.py u2_angle   # 只查一个单元
python3 tests/test_answers.py     # 回填标准答案，验证题答自洽（259 题）
python3 u2_angle/tests/test_unit.py   # 该单元几何断言 + 交互巡检 + 样式自检
python3 tests/make_preview.py     # 重新生成预览图
python3 tests/make_contact.py     # 生成各 section 截图联系表（人工过目用）
```

> `tests/contact/` 下会生成每个 section 的截图与一张联系表 `index.html`，
> 用于"逐 section 人工过目"（排版、留白、投屏可读性）。**自动断言抓不到"形状画错"**，
> 这一步不能省——本轮就是靠它抓到"射线被画成实心楔形""直角梯形画成了等腰梯形"两处问题。

`tests/audit.py` 覆盖的检查项：

| 层 | 检查项 |
|---|---|
| 结构 | 无外部资源引用（CDN/字体/外链）、`lang`/`title`/`viewport`、打印样式、相对路径有效 |
| 内容 | 导航锚点有对应 section、**显示题数 == 标称总题数**、题目数 == 答案数 == 解析数、解析非空、每题有答案、口径关键词齐全 |
| 交互 | 零 console error / pageerror、答对计分 +1、"重做本档"原地重建且计分归零、**答错文案不含正确答案**、填空答案归一化（"180" / "180度" / "180°" 都算对）、打印模式隐藏按钮且答案区可见 |
| 视觉 | **SVG 元素出框检查**（`getBBox()` 与 `viewBox` 比对）、各单元几何断言（"图 = 数"同源） |

> 注：`tests/test_unit.py` 还会检查 **CSS 自定义属性是否生效**——
> 早期版本曾因 `:root` 规则被破坏导致按钮白底白字、肉眼极易漏检，因此此项已固化为自动断言。
