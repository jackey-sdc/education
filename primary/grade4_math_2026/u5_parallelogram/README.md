## 课件结构

### 一、动画课堂（6 个模块）

1. **平行与垂直** —— 滑块切换两条直线的三种位置关系（平行 / 相交 / 垂直），
   垂直时自动画出直角符号；强调"平行与垂直都必须在同一平面内"。
2. **画垂线** —— 三步动画演示"① 三角尺一条直角边与已知直线重合 ② 另一条直角边过点画线
   ③ 标直角符号"，并指出垂线段就是点到直线的距离。
3. **点到直线的距离** —— 拖动点 P，课件同时画出三条连线并**标出各自长度**，
   学生直观看到"垂线段永远最短"。
4. **平行四边形** —— 拖动倾斜角与高：底、高标注在图上，
   实时显示周长与面积，结论是"**底和高不变时面积不变，倾斜使腰变长、周长会变**"。
5. **梯形** —— 一般 / 等腰 / 直角三种梯形切换，标出上底、下底与高，说明高的画法。
6. **四边形家族图** —— 树状分类图（四边形 → 平行四边形/梯形 → 长方形/正方形/等腰梯形…），
   点任一节点显示定义，突出"**分类要用一个标准**"。

平行与垂直 · 画垂线 · 点到直线的距离 · 垂线段最短 · 平行四边形的特征与底高 ·
梯形（等腰梯形、直角梯形）· 四边形分类思想 · 周长与面积启蒙 · 剪拼与等积变形
