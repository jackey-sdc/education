## 课件结构

### 一、动画课堂（4 个模块）

1. **单式条形统计图** —— 拖动"1 格代表几"（1~5），纵轴上限、直条高度与数据标签
   实时联动，直接体会"纵轴刻度怎么选"。
2. **复式条形统计图** —— 五步画法动画（定标题与单位 → 画第一组 → 画第二组 → 写图例 → 检查），
   两组直条并排、宽窄一致、间隔相同，含图例与数值标注。
3. **数据的收集与整理** —— "① 定目的 → ② 用'正'字记数据 → ③ 整理成统计表 → ④ 画条形统计图"
   四步流程，每一步都有对应的呈现。
4. **读图分析** —— 复式图 + 四个递进问题（读数 → 相差最大的一天 → 求和 → 为什么用复式图），
   给出完整分析文字。

### 三、知识点覆盖

单式与复式条形统计图 · 图例 · 数据收集与"正"字记录 · 读图分析与提出建议 ·
条形图与折线图的选择
