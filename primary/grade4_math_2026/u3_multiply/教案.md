# 第三单元《多位数乘两位数》教学设计

> 人教版（2024 年审定）四年级数学上册 · 配套课件 `index.html`（9 个课时）

## 一、教材分析

本单元把整数乘法的重点从"一位数乘多位数"推进到"**多位数乘两位数**"，
并在此基础上发展三条重要经验：竖式算理（数位对齐、从低位算起、满几进几）、
**积的变化规律**、**估算**。

学生已有的"一位数乘多位数"经验是起点，但真正的难点是**第二个因数有两位**带来的两次部分积，
以及"因数中间或末尾有 0"时 0 的处理。课件把竖式做成逐格高亮的动画，
让"进位去哪了""部分积为什么左移一位"变得可见。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 会口算整十整百数乘整十数；会笔算两、三位数乘两位数；掌握因数中间或末尾有 0 的乘法；理解积的变化规律；会用估算解决实际问题 |
| 过程方法 | 在竖式的"算理—算法"过程中说清每一步的道理；用"藏 0"理解口算与笔算的联系 |
| 情感态度 | 感受运算律与估算的现实价值，养成"算完检验"的习惯 |

## 三、教学重点与难点

- **重点**：多位数乘两位数的竖式算理与算法；积的变化规律。
- **难点**：连续进位；因数末尾有 0 时"积的末尾 0 的个数"；因数**中间**有 0 时 0 不能去掉。

## 四、教学准备

课件 `index.html`、竖式格尺（可用方格纸替代）、计算器（用于检验）。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 口算乘法（整十整百数相乘） | ① 口算乘法 | "藏起 0 → 算前面的数 → 添上 0"三步 |
| 2 | 口算乘法（两位数乘整十数） | ① 口算乘法 | 对比"20×30"与"120×30"的藏 0 方式 |
| 3 | 笔算乘法（两位数×两位数） | ② 笔算乘法 | 逐格动画：先算个位，再算十位 |
| 4 | 笔算乘法（三位数×两位数） | ② 笔算乘法 | 重点看第二次部分积为什么左移一位 |
| 5 | 因数末尾有 0 的乘法 | ③ 因数有 0 | 先去掉末尾 0 再算，最后添回去 |
| 6 | 因数中间有 0 的乘法 | ③ 因数有 0 | 对比 160×30 与 25×40，强调中间 0 占数位 |
| 7 | 积的变化规律 | ④ 积的变化规律 | 滑块 + "÷2 / ×3"按钮，看积怎么变 |
| 8 | 估算 | ⑤ 估算 | 把因数看成整十整百数；判断"够不够" |
| 9 | 整理与练习 | 练习区 | 第一、二档当堂；第三档作业 |

### 课堂节奏（以第 4 课时"三位数×两位数"为例）

1. **复习（3 分钟）**：课件第 ① 模块，快速口算 20×30、300×40，说清"藏 0"的道理。
2. **猜想（2 分钟）**：出示 236×34，先让学生估一估积大约是多少（300×30=9000）。
3. **探究（12 分钟）**：切到第 ② 模块，选 236×34，逐步点"下一步"。
   每次停下来问："现在算的是哪一位？""进位写在哪里？""第二行部分积为什么往左移一位？"
4. **辨析（5 分钟）**：课件第 ③ 模块，25×40 与 160×30 对比，追问"160 中间的 0 能不能去掉"。
5. **练习（12 分钟）**：第一档 + 第二档"竖式填空"当堂完成。
6. **小结（3 分钟）**：板书竖式三要求 + 积的变化规律。

## 六、板书设计

```
                多位数乘两位数
  口算：整十整百数相乘 → 藏起 0 → 先算 → 末尾添 0（几个 0 数清楚）
  笔算：① 相同数位对齐（第二个因数的个位对齐第一个因数的个位）
        ② 从个位算起  ③ 满几进几（进位的小 1 写清楚）
        ④ 第二次部分积左移一位
  末尾有 0：只去掉末尾的 0；中间的 0 占着数位，不能去掉
  积的变化规律：一个因数不变，另一个因数乘（除以）几，积就乘（除以）几
  估算：把因数看成最接近的整十整百数
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 竖式第二个因数没有对齐个位 | 课件竖式动画中两个因数逐格对齐，错的写法会明显偏一格 |
| 忘记加进位或进位写错位置 | 动画中"正在算"面板实时显示 `3 × 4 + 进位 1 = 13`，进位是加在前一位上的 |
| 第二行部分积没有左移一位 | 动画中两次部分积分别显示，并标出"左移一位" |
| 把 160 中的 0 也去掉 | 课件第 ③ 模块明确提示"因数中间的 0 不能去掉，它占着数位" |
| 积的变化规律用反 | 课件第 ④ 模块的 "÷2 / ×3" 按钮直接演示逆推 |
| 估算时把因数看得很粗糙 | 课件第 ⑤ 模块同时显示估算值与精确值，并指出估算偏大/偏小 |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"（竖式过程、估算与实际应用）12 题。
- **单元作业**：第三档"扩展思维"（规律逆推、简便算法、综合应用）12 题。
- **评价建议**：竖式题除结果外，要求学生**写出算理一句话**（如"因为第二个因数十位是 3，
  所以部分积要左移一位"），作为口头说理评分点。
