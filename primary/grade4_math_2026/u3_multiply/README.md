## 课件结构

### 一、动画课堂（5 个模块）

1. **口算乘法** —— 5 道题"① 藏起 0 → ② 算前面的数 → ③ 写得数 → ④ 添上 0"分步演示，
   并显示"两个因数末尾一共有几个 0"。
2. **笔算乘法（核心）** —— 可交互**竖式**，分两个阶段：
   - **阶段① 算部分积**：每点一次"下一步"只算一位，高亮当前格子，右侧说明"正在算 5 × 1 = 5""在十位写 5"，
     进位实时显示；
   - **阶段② 相加得积**：两个部分积按列相加，个位→千位逐位写出并标出进位。

   部分积采用**人教版写法**：十位上的数乘得的积**末尾补 0**，写成左移后的完整积
   （145×12 → 部分积 290 与 **1450**，竖式里 290 + 1450 = 1740 逐列对得上）。
   第 0 步只显示两个因数，**不会提前泄露答案**。内置 145×12、236×34、307×25、48×27 四道题。
3. **因数中间或末尾有 0** —— 区分"末尾的 0 可以藏起来""中间的 0 占着数位不能去掉"。
4. **积的变化规律** —— 滑块改变第二个因数，配合"÷2 / ×3"按钮，观察积同比扩大或缩小。
5. **估算** —— 选择"看成整百/整十"策略，同时显示估算值与精确值，并给出"够不够"的判断依据。

### 二、分层练习（共 40 题）

| 组别 | 题量 | 题型 |

## 课程讲解（语音 + 动画）

五个知识点各配一份六拍讲解（读信息→提问→找关系→算一算→检验→迁移），
点知识点卡片里的「🔊 开始讲解」播放；支持暂停/继续/停止/重播/语速，**点任意一拍可单独重讲**。

脚本在 `narr.js`（每 section 一个对象），动画由 `app.js` 末尾的 `MOD.*` 控制器驱动，
产物 `index.html` 由 `python3 ../build.py u3_multiply` 生成。改脚本后必须重建，再跑：

```bash
# 在仓库根目录执行
python3 .workbuddy/skills/math-courseware-explainer/scripts/check_explain.py u3_multiply
```

### 语音：预生成音频（晓晓音色，内联进单文件）

30 拍全部预生成音频并以 base64 内联，**音质与学生电脑装没装中文语音无关，也不需要联网**。
音频按「section id + 拍序」命名（如 `s-oral-1`），存放在 `assets/audio/u3/`，
`build.py` 注入 `window.NARR_AUDIO` 查表，`Narrator` 按同一规则查；查不到自动回退系统语音。

- 文案：`say` 为口语稿（平均 29 字/拍），`emp` 标重读（每拍 1 处）
- 音频：30 条 / 4.2 分钟 / 2078 KB / 64kbps 单声道 AAC
- 改文案后**必须**重新合成再构建，否则页面里还是旧音频：

```bash
python3 tools/tts_build.py u3_multiply     # 增量；改了切分规则用 --force
python3 build.py u3_multiply
python3 tools/check_audio_play.py u3_multiply   # 闸②：音频真在播
python3 tools/check_pron.py u3_multiply        # 闸③：数字读法
python3 tools/make_preview.py u3_multiply      # 试听页
```
