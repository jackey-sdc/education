1口算乘法

动画先算前面两个数，再在积的末尾添 0

整十数、整百数相乘，可以先算"去掉 0 后的数"，再在积的末尾添上同样多的 0。 点"算一算"看每一步。

2笔算乘法

核心动画竖式一步一步算

选一道题，点"下一步"，看清楚竖式里先算什么、再算什么、满几进几。 注意：相同数位要对齐，从个位算起。

要点笔算乘法的三个"对齐"

  • 数位对齐：第二个因数的个位要和第一个因数的个位对齐。
  • 从低位算起：先算个位，再算十位……
  • 满几进几：哪一位上的积满几十，就向前一位进几；进位的小 1 要写清楚。
  • 算完不要忘记把进位加上去；末尾有 0 的因数，积的末尾 0 的个数要看清楚。

3因数中间或末尾有 0 的乘法

动画0 的个数，藏在哪里？

点"算一算"，看因数末尾的 0 到底该在哪里"藏起来"。

拖动滑块改变第二个因数，看看积怎么变。也可以点" ÷2 / ×3"让积倒着变。
