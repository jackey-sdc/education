# 第七单元《复习与关联》教学设计

> 人教版（2024 年审定）四年级数学上册 · 配套课件 `index.html`（5 个课时）

## 一、教材分析

复习单元不是"把本册重讲一遍"，而是**让学生把知识连起来**：
一是从"知识点"走向"知识网络"（数与代数、图形与几何、统计三条主线）；
二是从"会做"走向"会联系"（同一个知识在不同情境中怎么用）；
三是引入**数学广角·鸡兔同笼**，把"假设法"作为一种通用的解题策略。

2024 版新教材在"复习与关联"中安排了"整理复习"与"应用提升"两个板块，
并把综合与实践《寻找宝藏》（用方向与位置描述路线）纳入本单元。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 能画出本册知识结构图；说清各单元核心概念；会用假设法解决鸡兔同笼；会用"方向 + 格数"描述位置 |
| 过程方法 | 经历"梳理—归类—联系—应用"的复习过程；体会假设法的一般性 |
| 情感态度 | 产生"数学知识是有结构的"的认同感；乐于用数学解决新情境中的问题 |

## 三、教学重点与难点

- **重点**：知识网络的内化；鸡兔同笼的假设法与检验意识。
- **难点**：把分散的知识点**关联**起来（如"数的改写与估算"属于同一条链）；
  假设法中"差 ÷ 2"的来历与最后的检验。

## 四、教学准备

课件 `index.html`、方格纸（画藏宝图）、小棒（摆鸡兔）、四色便利贴（做知识卡片）。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 整理复习：全册知识地图 | ① 全册知识地图 | 学生先自己画，再对照课件补全；说说哪一块最熟、哪一块最怕 |
| 2 | 整理复习：数与代数、图形与几何、统计 | ②③④ | 三条主线各做一次"知识链"梳理 |
| 3 | 数学广角：鸡兔同笼 | ⑤ 鸡兔同笼 | 假设—对比—调整—检验四步 |
| 4 | 综合与实践：寻找宝藏 | ⑥ 寻找宝藏 | 按指令在方格图上走，最后描述宝藏位置 |
| 5 | 应用提升与整理 | 练习区 | 第三档作单元检测；错题归因到具体单元 |

### 课堂节奏（以第 3 课时"鸡兔同笼"为例）

1. **暴露思维（5 分钟）**：让学生列"鸡兔同笼"的所有可能，体会"逐一列举"的局限。
2. **猜想（3 分钟）**：引导猜想"全当成鸡会怎样"，课件同步演示。
3. **探究（10 分钟）**：课件第 ⑤ 模块四步动画，重点讲清：
   每换一只鸡为兔，脚就**多 2 只**；差多少 ÷ 2 = 要换多少只。
4. **变式（6 分钟）**：拖动滑块改变头数脚数，让学生发现"有些数据不对应整数只"，
   体会数据本身的合理性。
5. **迁移（6 分钟）**：讨论"假设法还能用在哪里"（如船与人、票价与人数），实现方法的一般化。
6. **练习与小结（5 分钟）**：第一、二档相关题当堂完成。

## 六、板书设计

```
              复习与关联
  知识网络：
    数与代数：数位顺序表 → 分级 → 读写 → 比较 → 改写(＝)/近似(≈)
              口算 → 笔算 → 因数有 0 → 积的变化规律 → 估算
              加法模型（总量=分量+分量）  乘法模型（单价×数量=总价；速度×时间=路程）
    图形与几何：线段射线直线 → 角的度量 → 平行与垂直 → 平行四边形与梯形
    统计：收集 → 记录 → 整理 → 画条形图 → 分析
  数学广角·鸡兔同笼：假设全鸡 → 比脚数 → 差 ÷ 2 = 兔 → 检验
  综合实践·寻找宝藏：用"方向 + 格数"描述位置
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 鸡兔同笼逐一列举，数据大时算不完 | 对比"列举法"与"假设法"在数据量大时的效率 |
| 只算出兔几只就作答，不检验 | 课件最后一步自动显示"兔×4 + 鸡×2 = 实际脚数 ✓"，把检验变成习惯 |
| 差 ÷ 2 的道理说不清 | 用"每换一只多 2 只脚"这句话支撑，板书在旁边 |
| 走迷宫时走错方向 | 课件第 ⑥ 模块每条指令都有高亮与路径；强调先看方向再数格数 |
| 知识复习变成"重新讲一遍" | 让学生先输出、教师后补充；用"知识地图"当主线而不是章节顺序 |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"（鸡兔同笼、藏宝图、统计与图形）9 题。
- **单元作业**：第三档"扩展思维"（综合应用、易错辨析）10 题。
- **单元检测建议**：把第三档 10 题改编为 6 题闭卷检测；
  错题让学生**归因**到具体单元（数与代数 / 图形与几何 / 统计），形成补救清单。
