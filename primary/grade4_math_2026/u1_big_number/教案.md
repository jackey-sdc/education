# 第一单元《万以上数的认识》教学设计

> 人教版（2024 年审定）四年级数学上册 · 配套课件 `index.html`（8 个课时）

## 一、教材分析

本单元是小学阶段"数的认识"的最高点。三年级已认识万以内的数，本单元把数的范围扩展到"亿"，
并由此引出**分级、计数单位、改写与求近似数**等一系列新概念。
学生要经历"十进制计数法 → 数位顺序表 → 分级 → 读写 → 比较 → 改写/估算"的完整链条。

单元末尾的**综合与实践《1 亿有多大》**，把抽象的数落到"一张纸有多高""一粒米有多重"等可感知的
生活情境上，是本单元落实"用数学解决实际问题"的重要落点。

## 二、教学目标

| 维度 | 目标 |
|---|---|
| 知识技能 | 知道数位顺序表与各计数单位；会读写亿以内、亿以上的数；会比较大数的大小；会把整万、整亿数改写成用"万""亿"作单位的数；会用四舍五入法求近似数 |
| 过程方法 | 经历"分级—数位对齐"的读数过程；在数位表上操作体会十进制；用"1 亿有多大"的估算发展数感 |
| 情感态度 | 感受"亿"这个数与日常经验的巨大落差，产生对大数的好奇与估算意识；养成"改写用＝、估算用≈"的严谨习惯 |

## 三、教学重点与难点

- **重点**：亿以内、亿以上数的读写；亿以上数的改写与近似数。
- **难点**：中间或末尾有 0 的数的读写（每级末尾 0 不读、其他数位连续 0 只读一个"零"）；
  "改写"与"求近似数"的区别（等号 vs 约等号）。

## 四、教学准备

- 教师：课件 `index.html`（投影）、实物投影仪或大屏。
- 学生：数位顺序表学具（可选）、练习纸。
- 环境：课件为单文件零依赖，**可断网离线运行**，教室电脑直接双击打开即可。

## 五、课时安排与教学流程

| 课时 | 内容 | 课件模块 | 关键活动 |
|---|---|---|---|
| 1 | 亿以内数的认识（数位顺序表） | ① 数位顺序表 | 点击计数单位，说名称与进率；"10 个一万 = 1 个十万"演示 |
| 2 | 亿以内数的读法 | ② 认识大数（分级读数器） | 输入数 → 分级 → 一级一级读，强调"每级末尾 0 不读" |
| 3 | 亿以内数的写法 | ② 写数模块 | 从读法还原到数位，没占到数位写 0 占位 |
| 4 | 亿以上数的认识与读写 | ② 认识大数 | 读 3200000000、1200000000，亿级从最高位读 |
| 5 | 大数的大小比较 | ③ 大小比较 | 先看位数，再一位一位比（12 亿 = 120000 万） |
| 6 | 数的改写 | ④ 数的改写 | 拖滑块观察"末四位是 0"才能改写，强调用等号 |
| 7 | 求近似数 | ⑤ 求近似数 | 四舍五入：省略万位看千位、省略亿位看千万位，用约等号 |
| 8 | 综合与实践《1 亿有多大》 | ⑥ 1 亿有多大 | 估算：纸币堆高度、大米重量、时间、步数；交流"大约"的合理性 |

### 课堂节奏（以第 6 课时"数的改写"为例）

1. **情境引入（3 分钟）**：出示 12000000 与 1200 万，问"这两个数一样大吗？"
2. **探究新知（12 分钟）**：切到课件第 ④ 模块，拖动滑块，让学生找出"什么时候能用＝改写"。
   归纳：末四位是 0 → 改写成"万"；末八位都是 0 → 改写成"亿"。
3. **辨析（6 分钟）**：对比"改写（＝）"与"省略尾数求近似（≈）"，让学生举例说区别。
4. **练习（10 分钟）**：第一档"巩固基础"当堂完成，答错看提示回看第 ④⑤ 模块。
5. **小结与作业（4 分钟）**：布置第二档（动手）与第三档（扩展）作业。

## 六、板书设计

```
                万以上数的认识
  数位顺序表：个 十 百 千 | 万 十万 百万 千万 | 亿 十亿 百亿 千亿
  分级：      亿级        | 万级           | 个级
  读数：最高级读起，每级末尾的 0 不读，其他 0 只读一个"零"
  比较：位数多的数大 → 位数相同从最高位比起
  改写（=）：末四位是 0 → 改写成"万"；末八位是 0 → 改写成"亿"
  近似（≈）：四舍五入；省略万位看千位，省略亿位看千万位
```

## 七、常见错误与纠正

| 错误 | 纠正办法 |
|---|---|
| 把 3004000 读成"三百万零四千" | 用课件②的分级高亮图数一数：万级 300、个级 4000，个级没有中间的 0，不读"零" |
| 改写与求近似数混用符号 | 板书固定并列两个式子：500000 = 50 万（＝）、496800 ≈ 50 万（≈） |
| 认为"495600 = 49.56 万"是改写 | 改写只针对整万/整亿数；先看末四位是不是 0 |
| 四舍五入看错数位（省略万位却看百分位） | 课件⑤会把"要看的那个数字"高亮成橙色 |
| 比较大数时只比前几位就下结论 | 用课件③的逐步比较动画，强调"从最高位起逐位比，直到分出大小" |

## 八、作业与评价

- **课堂作业**：第二档"动手操作"（分级、组数、数位填空）9 题。
- **单元作业**：第三档"扩展思维"（近似数的范围、1 亿有多大推理）11 题。
- **评价方式**：课件内三档独立计分，可单独重做；答案与解析在页面末尾折叠区。
- **单元检测建议**：把第三档改编为 4~5 道口头答辩题，重点问"你是怎么判断 386500 ≈ 39 万的"。
