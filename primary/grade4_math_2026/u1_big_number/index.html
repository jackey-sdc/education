1数位顺序表 · 计数单位

动画从"个"到"亿"：满十进一，两个大单位换一个大单位

数位顺序表从右往左依次是个位、十位、百位、千位、万位……每相邻两个计数单位之间的进率都是 10。 点击表格中的任意一个计数单位，看看它的名称、读写方式，以及"10 个它 = 1 个谁"。

要点分级：从右往左每四位分一级

数位级包含的数位计数单位
亿级亿位、十亿位、百亿位、千亿位亿、十亿、百亿、千亿
万级万位、十万位、百万位、千万位万、十万、百万、千万
个级个位、十位、百位、千位个、十、百、千

分级的方法：从右边起，每四个数位为一级；不够四位的，前面补 0。 分级后，从最高级起读，每一级都按"个级"的读法读，读完加该级的名称。

易错提醒：每级末尾的 0 都不读；其他数位有一个 0 或连续几个 0，都只读一个"零"。

4数的改写：把整万、整亿的数写简便

动画改写用等号"＝"

拖动滑块选一个整万数，看看它怎么改写成用"万"或"亿"作单位的数。 拖动滑块时注意：只有末四位是 0 的数才能改写成"万"，只有末八位都是 0 的数才能改写成"亿"。

—
关键区别：改写是准确数，大小没变，用"＝"；求近似数是估计数，大小变了，用"≈"。

要点亿级数的认识小结

  • 十进制计数单位：个、十、百、千、万、十万、百万、千万、亿、十亿、百亿、千亿……
  • 相邻两个计数单位之间的进率是 10；10 个一千万是 1 个亿。
  • 读数：先分级，从最高级读起，每级末尾的 0 不读。
  • 写数：先分级，哪一位上一个单位也没有就写 0 占位。
  • 比较：位数多的数大；位数相同，从最高位比起。
  • 改写（＝）：整万数改写成用"万"作单位的数，整亿数改写成用"亿"作单位的数。
  • 求近似数（≈）：四舍五入到万位看千位，到亿位看千万位。
