# 交互式科学教育辅助系统设计风格指南

## 设计目标
- **核心诉求**：高级、有质感、专业、沉浸感
- **避免**：拥挤、廉价感、杂乱、过时的设计

## 视觉风格
- **主风格**：暗黑模式极简 + 玻璃态毛玻璃效果
- **辅助描述**：优雅的留白、精致的微交互、有层次的阴影、高级的渐变

## 排版
- **字体**：
  - 无衬线体：'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
  - 衬线体：'Georgia', serif
  - 等宽字体：'Fira Code', monospace
- **字重**：
  - 标题：700-800
  - 副标题：600
  - 正文：400-500
- **行高**：1.6

## 布局
- **网格系统**：基于12列网格
- **间距**：
  - xs: 0.25rem
  - sm: 0.5rem
  - md: 1rem
  - lg: 1.5rem
  - xl: 2rem
  - 2xl: 3rem
  - 3xl: 4rem
- **圆角**：
  - sm: 0.25rem
  - md: 0.5rem
  - lg: 1rem
  - xl: 1.5rem
  - full: 9999px

## 核心组件

### 玻璃态卡片
```html
<div class="glass card">
  <!-- 内容 -->
</div>
```

### 渐变按钮
```html
<button class="gradient-btn">按钮文本</button>
```

### 进度条
```html
<div class="progress-bar">
  <div class="progress-fill" style="width: 75%"></div>
</div>
```

### 标签
```html
<span class="knowledge-tag">标签文本</span>
```

### 徽章
```html
<span class="difficulty-badge difficulty-medium">中等</span>
```

## 动画效果
- **过渡**：0.3s ease
- **悬停效果**：轻微上浮、阴影加深
- **加载动画**：旋转加载
- **渐变动画**：背景渐变流动

## 响应式设计
- **断点**：
  - 移动端：< 768px
  - 平板：768px - 1024px
  - 桌面：> 1024px
- **布局调整**：
  - 移动端：单列布局，隐藏导航菜单
  - 平板：双列布局，简化导航
  - 桌面：多列布局，完整导航

## 可访问性
- **对比度**：符合WCAG 2.1标准
- **键盘导航**：支持Tab键导航
- **屏幕阅读器**：支持ARIA标签
- **减少动画**：尊重prefers-reduced-motion设置
