二次函数图像与性质

📐 数学
中等
⏱️ 10分钟

已知二次函数 f(x) = ax² + bx + c 的图像经过点 (0, 3)，且当 x = 1 时取得最小值 2，求函数的解析式。

二次函数 顶点式 最小值

解题步骤

步骤 1：确定二次函数的顶点式
由于二次函数在 x = 1 时取得最小值，因此顶点坐标为 (1, 2)，可以设函数的顶点式为 f(x) = a(x - 1)² + 2。
步骤 2：利用已知点求参数 a
函数图像经过点 (0, 3)，代入顶点式得：3 = a(0 - 1)² + 2，解得 a = 1。
步骤 3：展开顶点式得到一般式
将 a = 1 代入顶点式，展开得：f(x) = (x - 1)² + 2 = x² - 2x + 3。
