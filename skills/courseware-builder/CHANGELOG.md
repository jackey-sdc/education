# 变更记录

格式：`## [版本] - 日期` → 本次改了什么、为什么。

## [1.1.0] - 2026-10-21
- 通用化：从"数学课件专用"重构为**任意学科的互动课件**生成器
  - SKILL.md 上位原则化：口径先行 / 证据优先 / 模块化一次成型
  - 新增 `references/graphics.md`：绘图正确性手册（坐标约定、弧线方向、出框、遮挡、验证方法）
  - 新增 `references/patterns.md`：七种可视化模式 + 各学科适配建议
  - 新增 `references/pipeline.md`：本仓库 `grade4_math_2026` 单元流水线与共享引擎 API
- 模板改为通用骨架：分步演示 + 参数动画/对比实验两种模式示例（原先只有数学角度示例）
- 自检脚本升级为**四层**（结构 / 内容 / 交互 / 视觉），视觉层用几何断言

## [1.2.0] - 2026-10-21
- 新增**自迭代机制**：`LESSONS.md` 经验沉淀表 + 本文件变更记录 + `scripts/self_check.py` 健康检查
- 新增 `install.sh`：把 skill 同步到 `~/.codex/skills/` 以便 Codex 自动发现（仓库为唯一真源）
- `self_check.py` 增加"仓库源 vs 已安装副本"漂移检测，防止改完忘记同步

## [1.3.0] - 2026-10-21
- **修复共享引擎 bug**（`primary/grade4_math_2026/assets/engine.js`）：同一档的 choice/fill 分两次挂载，
  后一次 `clear(host)` 覆盖前一次，导致 u1 课件**选择题整块消失**（15 题只显示 7 题，页面却看着正常）。
  改为一次性挂载全部题目。
- 自检脚本新增**通用内容层断言**：每个 `*Block` 的显示题数必须等于对应 `*Total`，
  这类"静默丢题"以后能被自动抓到。
- LESSONS 追加该经验（含根因、预防规则、回归测试出处）。

## [1.4.0] - 2026-10-22
- 用本仓库 `grade4_math_2026/` 的 7 个单元课件做了一轮完整验收，新增并落地：
  - `primary/grade4_math_2026/tests/audit.py` —— **四层验收脚本**（结构 / 内容 / 交互 / 视觉），
    覆盖：外部资源扫描、导航锚点、题目数 == 答案数 == 解析数、显示题数 == 标称题数、
    计分与重做、答错不泄露答案、填空答案归一化、打印模式、**SVG 出框**检查。
  - 各单元 `tests/test_unit.py` 补齐**几何断言**（量角器高亮弧的起止极角、竖式结果 == a×b、
    条形高度 ∝ 数值、鸡兔同笼兔数、藏宝终点、平行四边形面积等），实现"图 = 数"同源自动验证。
- **修掉 4 个真 bug**：打印样式漏掉 `ghost` 类按钮、u2 线/射线/直线模块标签出框、
  u2 练习内嵌钝角图被切、u7 图形模块角的水平边出框。
- LESSONS 追加 #11~#14（打印样式选择器陷阱、小图出框、**审计脚本自身也会测错**、单元名解析时机）。
- **人工过目截图又抓到 2 个"形状画错"**（自动断言抓不到，因为元素都在画布内）：
  - u2 线/射线/直线模块：箭头多边形用错了极坐标基准点 → 射线成实心楔形、直线箭头只剩 2px；
  - u5 梯形模块：三种梯形共用对称公式 → "直角梯形"实际画成了等腰梯形。
  两者都已修复，并补上**锁定义特征**的断言（箭头数量、直角梯形 D.x==A.x、等腰 dl==dr）。
- LESSONS 再追加 #15~#16（分类图要各自的几何参数、箭头要独立 helper）。
- **新增 #17：章节导航改用"左侧可折叠栏"**（而不是顶部横向导航条），并把"折叠—展开—恢复"
  做成自动回归检查（`tests/audit.py`）。

## [1.5.0] - 2026-10-24
- **新增 LESSONS #18~#21**（源自四上第三单元笔算竖式的真实返工）：
  - #18 竖式部分积必须写成**左移后的完整积**（145×1×10 = 1450），否则竖式里
    `290 + 145 ≠ 1740`，会被判为"算法是错的"；并点明
    **"位置自洽"≠"与教材一致"**，约定类问题自动断言验不了，必须对照教材人工核。
  - #19 逐步演示**不能提前填入最终答案**，未算出的格子要留空（否则动画是假的）。
  - #20 位名要按**结果实际所在列**表述（部分积左移 i 位 → 列 = j + i）。
  - #21 方法论：自动断言只守"不漂移"，教材约定要人工核 + 写进口径说明。
- `references/graphics.md` 新增「五之二、数位对齐类图形（竖式/数位表/统计表）」：
  部分积写法、占位 0 的出现时机、位名换算、不剧透原则、竖式自检断言写法。
- `references/pedagogy.md` 新增「八、逐步演示的"不剧透"原则」。
- `templates/visual_test.py` 增加两条可复制的断言示例：
  "逐步演示第 0 步不泄露结果"、"竖式：各部分积之和 = 结果"；
  并在开头点明"断言只验自洽、不验教材约定"。
- 依据新教材（人教版 2024 年审定）**四年级数学下册**做了一轮完整交付：
  `primary/grade4_math_2027/`（7 个单元 + 总览页，与上册 `grade4_math_2026/` 同构）。
- **新增"独立复算"验收脚本** `primary/grade4_math_2027/tests/check_answers.py`：
  用 Python 从题干解析算式、独立算出正确答案，与 `a:` 指向的选项文本比对。
  起因是发现一处**答案下标写错**（`a:2` 指向了第 3 个选项），而 `test_answers.py` 照样判"答对"——
  引擎与题目数据同源，两者一起错时自洽性测试**无法发现**。
  这是"证据优先"原则的一个新层次：**不仅验证内部自洽，还要独立复算**。
- `primary/grade4_math_2027/tests/test_unit.py` 新增 `CONCLUSION_ASSERTS`：
  点"完整演示"后必须能看到该模块的"教学口径"结论。起因是 `step` 被夹在 `length-1`
  而结论分支判断 `>= length`，**所有分步模块的结论都不可达**。
- 修掉 5 类真 bug（均有回归断言）：
  - `numberLine()` 覆盖宿主 svg 的 viewBox → 同图元素全部出框；
  - 面积模型画成 2×2 网格且下半部分高度为 0，与 `(a+b)×c` 的一维分割不符；
  - 三角形按角分类用 `tan(A)` 求顶点，A/B 接近 90° 时数值爆掉、图形消失；
  - `haloText()` 少传一个 `null` 参数 → `rotate(NaN ...)`；
  - 小数点对齐动画的小数点画在数字上，且演示用的算例两种列法结果相同（学生看不出错在哪）。
- LESSONS 追加 #18~#24（viewBox 覆盖、结论态不可达、答案下标自洽性盲区、面积模型维度、
  三角函数溢出、SVG 分层排版、按三边比例作图）。
- 人工过目截图又抓到 3 处"自动断言抓不到"的排版/作图问题（都已修复并补断言）：
  - 三边关系动画：不等式方框压住三角形，结论被遮；
  - 三边关系动画：画的三角形与标注的 A/B/C 长度**对不上**（改为按三边实际比例作图）；
  - 小数点对齐动画：小数点画在数字上，且演示用的算例两种列法结果**相同**（学生看不出错在哪），
    改用 1.2+0.68（末位对齐得 1.80，小数点对齐得 1.88，结果不同）。
