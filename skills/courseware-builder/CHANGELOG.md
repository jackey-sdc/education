  用 Python 从题干解析算式、独立算出正确答案，与 `a:` 指向的选项文本比对。

  点"完整演示"后必须能看到该模块的"教学口径"结论。起因是 `step` 被夹在 `length-1`
  而结论分支判断 `>= length`，**所有分步模块的结论都不可达**。
- 修掉 5 类真 bug（均有回归断言）：
  - `numberLine()` 覆盖宿主 svg 的 viewBox → 同图元素全部出框；
  - 面积模型画成 2×2 网格且下半部分高度为 0，与 `(a+b)×c` 的一维分割不符；
  - 三角形按角分类用 `tan(A)` 求顶点，A/B 接近 90° 时数值爆掉、图形消失；
  - `haloText()` 少传一个 `null` 参数 → `rotate(NaN ...)`；
  - 小数点对齐动画的小数点画在数字上，且演示用的算例两种列法结果相同（学生看不出错在哪）。
- LESSONS 追加 #18~#24（viewBox 覆盖、结论态不可达、答案下标自洽性盲区、面积模型维度、
  三角函数溢出、SVG 分层排版、按三边比例作图）。
- 人工过目截图又抓到 3 处"自动断言抓不到"的排版/作图问题（都已修复并补断言）：
  - 三边关系动画：不等式方框压住三角形，结论被遮；
  - 三边关系动画：画的三角形与标注的 A/B/C 长度**对不上**（改为按三边实际比例作图）；
  - 小数点对齐动画：小数点画在数字上，且演示用的算例两种列法结果**相同**（学生看不出错在哪），
    改用 1.2+0.68（末位对齐得 1.80，小数点对齐得 1.88，结果不同）。

  - 五星浅奥题需要**两步以上思考**（倒推中间量 / 两解辨析）。

  - 已做**防刷屏**处理：同屏点赞上限、横幅唯一、通关庆祝只触发一次。
- `templates/lesson-template.html` 同步加入星级与庆祝模块（新课件开箱即用）。
- LESSONS 追加 #25~#27（DOM 元素被当字符串拼接、庆祝刷屏、音频与"零依赖"约束的冲突）。

## [1.7.0] - 2026-10-25
- **新增「答案层」验收**（原则②"证据优先"的新一层）：
  - 起因：发现 `check_why_consistency()` **一直在静默空跑**——`re.split(r"\n\s*\{q:", ...)`
    把 `q:` 当分隔符吃掉了，后续 `search(r"q:'...'")` 恒为 `None`，每题都被 `continue` 跳过。
    校验脚本输出"全部通过 ✅"，实际**一条都没查**。
  - 新增 `references/answers.md` —— **答案正确性校验手册**：
    L1 自洽 / L2 独立复算 / L3 答案×解析交叉，三层互相独立；
    含"为什么不能用最后一个等号抽结论""信息不足型陷阱""校验脚本自身的三个坑""植入测试规范"。
  - 新增 `templates/check_answers.py` —— 可复用校验器模板（拷进 `tests/` 改档位名/字段名即可）。
- **修掉 4 类"校验器自身的坑"**（都曾让校验**漏报或误报**）：
  - `re.split` 吃掉字段名 → 改用**一条正则**同时抽 q/opts/a/why；
  - `Pattern.finditer(body, re.S)` 第二参数是 `pos` 不是 flags → flags 写进 `re.compile`，
    并加"解析条数与粗略计数**对账**"；
  - "取最后一个 `= 数字`"抽结论，实测 178 题**误报 17 处** → 改按语义分路
    （结论措辞 / 答案必现 / `→` 箭头结论 / 末句命中选项），实测**零误报**；
  - 抽数值前不剥 `<b>` 标签 → 把对的题误报成错的（结论值常写成 `'= <b>168</b>。'`）。
- **新增 4 条校验规则**（均配植入测试验证"真值零误报 + 植入必报"）：
  - 估算题不参与精确复算；
  - 归一化不删分隔符（`'3 cm、4 cm、5 cm'` 不能变成 `345`）；
  - "人数相同却没给人数"的题，答案不该是具体差值（**不依赖选项含"无法确定"**）；
  - 「哪一个的积/商是 N」型题**逐个复算选项**（选项本身就是算式，题干抽算式的路子用不上）。
- **回灌上册**：把 `scan_object_str()` 与 `check_answers.py` 都同步到 `primary/grade4_math_2026/`，
  两册各跑一遍均零问题——新增验收层后**必须回灌旧课件**，否则旧册子是盲区。
- **实测抓到并修复 3 处真错题**（不是误报）：
  - u3「两个内角 30° 和 45°」答案写成"锐角三角形"，实为**钝角**三角形；
  - u6「人数相同，总数多 8 棵 → 平均数多几棵」**信息不足**却把答案写死成"多 2 棵"；
  - 上册 u3/u6 同类问题各 1 处（经修正规则后复测均通过）。
- SKILL.md 新增「**分档与星级**」默认约定表（★★★/★★★/★★★★/★★★★★ + 三档反馈），
  验收层表格新增「**答案层**」，弯路表新增 4 条。
- `references/checklist.md` 新增「二之二、答案层」整节；
  `references/pipeline.md` 新增「八、答案校验（check_answers.py）」与星级分层/庆祝系统说明。

- **修掉 2 处真实内容错误**：
  - u3「等腰三角形的一个角是 40°，它的顶角是（　）」——**多解**
