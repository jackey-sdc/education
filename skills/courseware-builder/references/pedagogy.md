# 练习设计、反馈与教案的方法要点

## 一、三层结构（通用）

| 层 | 作用 | 通用题量 | 适合的题型 |
|---|---|---|---|
| 巩固 | 覆盖本课全部口径 | 12~16 | 选择、填空、判断、连线 |
| 动手 | 把概念变成操作 | 4~6 | 读图、测量、拖拽、自评 |
| 扩展 | 迁移与计算 | 10~15 | 选择、填空、简答 |

**原则**：概念题必须覆盖每条教学口径（本课讲了几条规则，选择题里就得有对应的题）；
扩展题里至少放一道**陷阱题**。

各学科的"动手"层设计参考：
- 数学：量角、数格子、拖动图形看变化
- 物理：调参数观察现象、预测结果再验证
- 化学：拖动配比、改变条件看产物
- 语文/英语：听辨、排序、仿写、跟读
- 信息科技：跑一段代码看中间变量

## 二、反馈三段式

```
答错 → ❌ 再想想～ + 可操作提示（指向某个动画环节，不给答案）
答对 → ✅ 答对了！ + 说理式解析（为什么是这个答案）
```

- 提示要**可操作**："把角的两条边拉长一点（动画 5-1），看看角度变没变"，
  而不是"再想想"或直接说结论。
- 解析要**说理**，不是重复答案："内圈 0° 在右端、外圈 0° 在左端；钝角要用左端那条 0 刻度线对齐，所以读外圈。"
- 答错不锁死，允许重试；答对后锁定选项。

## 三、干扰项设计

好的干扰项对应一个**真实的错误想法**：

| 正确 | 干扰项 | 对应的错误想法 |
|---|---|---|
| 115° | 65° | 内外圈读反 |
| 60° | 30° | 把角当成平角的一半 |
| 30° | 60° | 量的是补角 |
| 180° | 90° | 钟面 6 点当成 3 点 |

- 不要放明显离谱的选项（750°），那只是送分。
- 每题的干扰项最好能对应"教案常见错误表"里的一行——**错题与讲评一一对应**。

## 四、题干表述

- 填空统一用全角括号"（　）"，答案位数与括号宽度匹配。
- 数值答案不带单位写进括号（题干里已有"度"就别在括号再写"度"）。
- 判断题给"对/错"，不用 T/F（小学生不熟）。
- 题干尽量短，长题干会把考点藏起来。

## 五、口径一致性检查（最容易被忽略）

课件画法、题干表述、答案数值必须来自**同一份口径**。自检方法：

1. 把本课口径写成一句话，放进教案第一段；
2. 逐题问"这道题按这句话判，答案唯一吗"；
3. 图形课要用真实图形出题（学生会照着图读），图形必须按口径画。

反例：课件演示"钝角读外圈"，但练习图把 130° 画成内圈口径——
学生会照着图读出 50°，形成错误经验。

## 六、教案结构

```
一、教学目标        （知识 / 能力，分层写）
二、教学重点与难点  （难点单独列，并说明怎么突破）
三、教学准备        （实物教具、课件）
四、教学过程        （分课时：导入 → 新授 → 练习 → 小结 → 作业，每环节标注用时）
五、板书设计        （结构化文本，便于拍照/复现）
六、常见错误与纠正  （表格：错误表现 | 纠正方法）
七、作业设计        （基础 / 选做 / 实践）
八、评价方式        （课堂反馈、课后自评、操作达标标准）
```

**常见错误表**最有价值：直接来自练习中的错误反馈，逐条对应讲评顺序。

## 七、动画与练习的分工

- 动画负责**建立表象**（角怎么形成、量角器怎么用、边变长角不变）。
- 练习负责**暴露错误**（判断题查概念、陷阱题查操作）。
- 两者必须**同一套口径**。
