# 可视化模式库与学科适配

## 一、七种模式

每种模式给出：**适用场景 / 实现要点 / 验收方式 / 常见坑**。

### 1. 标注图示（静态）
- **适用**：讲结构、部件、术语（角的顶点与边、电路元件、植物结构）。
- **实现**：SVG 静态绘制 + 标注文字 + 引线；标注一律放图形**外侧**。
- **验收**：截图；检查标注是否出框、是否压住被标注对象。
- **坑**：引线与文字容易穿插；先排版再画引线，标注按上/下/左/右分四区避让。

### 2. 参数动画
- **适用**：讲变化与规律（角度变化、力的大小、速度与时间、函数图像）。
- **实现**：参数对象 → 渲染函数（纯函数，全量重绘）；播放用 `requestAnimationFrame` 插值，
  手动用滑块；两条路径共用渲染函数。
- **验收**：给定参数 → 几何断言（图形与参数一致）；断言播完后的终值。
- **坑**：动画插值与滑块不同步 → 只保留一个状态源。

### 3. 分步演示
- **适用**：讲操作流程（量角器三步法、实验步骤、解题步骤）。
- **实现**：步骤状态机 `step = 0..n`，每步只高亮一个要素并配一句解说；
  "完整演示"= 定时器串起各步。
- **验收**：每步一张截图；断言步骤数与高亮元素数。
- **坑**：一步里塞太多信息 → 一步一个要点。

### 4. 对比实验
- **适用**：讲变量控制、"变了什么"（边变长角不变、电流与电压、加速度与力）。
- **实现**：并排子图共享参数，**只让一个变量不同**；提供"改变某变量"按钮。
- **验收**：子图数量断言；共享参数一致性断言；被改变量差异断言。
- **坑**：对比时顺手改了多个变量，学生得出错误因果。

### 5. 模拟沙盒
- **适用**：动态系统（运动、碰撞、电路、水循环、粒子反应）。
- **实现**：状态机 + 时间步进（固定 dt）+ 可调参数 + 轨迹记录。
- **验收**：**不变量断言**（如总动量守恒、元素种类守恒、电荷守恒）；步进可复现（同参数同结果）。
- **坑**：用 `requestAnimationFrame` 的真实时间做物理 → 换设备结果不同；必须固定 dt。

### 6. 互动探索
- **适用**：学生自己玩中学（拖拽角、拖温度看溶解）。
- **实现**：拖拽/点击 + 实时反馈 + 撤销。
- **验收**：交互巡检（拖到极值、越界、快速连点）。
- **坑**：拖拽没有边界钳制 → 图形飞出画布。

### 7. 测验引擎
- **适用**：所有课件的巩固与拓展部分。
- **实现**：见 `pedagogy.md` 与模板的引擎层。
- **验收**：题数、计分、重做、答案条目数断言。

## 二、学科适配建议

### 数学
- 几何：图形必须**几何断言**（角度、比例、同心）；角/线段/数量用元素计数断言。
- 数与代数：数轴、竖式、分数条——用**位置/长度比例**断言。
- 统计：条形/折线/扇形——用**数据与图形的对应关系**断言（图上柱高 = 数据值 × 比例）。
- 规律：找规律的表格，把"下一项"做成参数，断言第 n 项的取值。

### 物理
- 受力图：力的方向、箭头长度与大小成正比——**箭头长度断言**。
- 运动：位置—时间图、速度—时间图，断言斜率与面积含义。
- 电路：串并联电路的电流电压，用节点守恒断言。
- 光路：反射角=入射角，**角度断言**（这是最容易被画反的）。
- 通用：**能量/动量/电荷守恒**作为不变量断言。

### 化学
- 分子模型：原子个数守恒（反应前后逐一对应）。
- 反应速率曲线：浓度、温度与速率的定性关系，断言单调性而非具体数值。
- 溶解：饱和溶液——加溶质后未溶量不增加，可断言。

### 语文 / 英语
- 汉字笔画：笔顺编号与方向断言（起点、终点坐标）。
- 文本朗读/跟读：与浏览器 SpeechSynthesis 集成，注意**离线不可用**，要降级。
- 句型对比：并列图示 + 划线标注。

### 地理
- 地图/地球仪：经纬度位置断言；昼夜、季节用角度（太阳高度角）驱动。
- 时区：同一时刻不同经度的地方时 = 角度差 ÷ 15。

### 信息科技（编程启蒙）
- 算法可视化：数组/排序/递归——断言**数组状态**而非像素，最可靠。
- 流程图执行：高亮当前节点，断言执行序列与预期一致。
- 调试演示：故意写错的代码，用"运行看结果"演示错误。

## 三、跨学科通用经验

1. **数字要有意义**：动画里的数值要么来自参数，要么来自真实数据；不要"看起来差不多"。
2. **一图一意**：一个动画对应一句教学结论；配一句"这个动画让你看出什么"。
3. **同一概念全课同色**：跨模块保持颜色/符号一致。
4. **动画可暂停可复位**：教师常需要停在某一帧讲解，所有动画提供复位。
5. **投屏可读**：正文字号 ≥ 15px，图形内文字 ≥ 12px；关键数值用大号加粗。
6. **降级预案**：需要联网/外部资源时（语音、外部数据），准备离线可用的简化路径。
