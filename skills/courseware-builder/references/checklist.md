# 交付前自检清单

六层验收：**结构 → 内容 → 答案 → 语义 → 交互 → 视觉**。带 ⚠️ 的是实战踩过的坑。

## 〇、交付物

- [ ] `index.html`（主课件）、`教案.md`、`README.md`、`preview.png`、`tests/`
- [ ] ⚠️ 课件**不引用任何外部资源**（CDN/字体/图片外链）——断网、投影、家长手机都要能开
- [ ] 打印样式生效：隐藏导航与按钮，题目不跨页断开，答案区可展开
- [ ] 相对路径引用（整体移动目录后不失效）
- [ ] 路径已登记到所在平台/目录（如 education 平台的左侧目录）

## 一、结构层（脚本可查）

- [ ] ⚠️ 无外部引用：`grep -E '(src|href)\s*=\s*["'"'"']https?://' index.html` 无命中
      （SVG 命名空间 `http://www.w3.org/2000/svg` 不是网络请求，不用排除）
- [ ] 字体用系统栈、图标用 emoji 或内联 SVG
- [ ] HTML 有 `lang="zh-CN"`、`<title>`、viewport

## 二、内容层（脚本可查 + 人工核）

- [ ] ⚠️ **口径先定死**，且三条链路同源：**课件演示 → 练习题干 → 答案解析 → 教案表述**
- [ ] ⚠️ 题目数 = 答案条目数 = 解析数（脚本比对）
- [ ] 术语表述准确、无自相矛盾（例：写角时中间字母是顶点，`∠AOB` 与 `∠BOA` 是同一个角）
- [ ] 图形上的数值与文案一致（图标 45°，文字别写 40°）
- [ ] 教案内的时间分配、作业量与真实课时匹配
- [ ] 常见错误表来自真实错误反馈，不是编的

## 二之二、答案层（脚本可查，**最容易漏掉的一层**）

- [ ] ⚠️ **答案被独立复算过**（不靠引擎自证）：`python3 tests/check_answers.py` 退出码为 0
- [ ] ⚠️ **答案与解析交叉校验过**（`a:` 与 `why:` 是分别写的，会打架）
      —— 详见 `references/answers.md`
- [ ] ⚠️ **校验脚本不是空跑**：做过**植入测试**（植入一处该规则该抓到的错 → 必须报错；还原 → 必须全绿）
      —— 校验脚本自己出错时，输出同样是"全部通过 ✅"
- [ ] 估算题 / 概念题 / 多解题**不参与精确复算**（否则误报）
- [ ] "人数相同/同样多"但没给人数的题，答案**不是**具体差值
- [ ] 「哪一个的积/商是 N」型题，**逐个复算选项**确认只有一项成立

## 二之三、语义层（脚本 + 人工，**算术对不等于题意对**）

- [ ] ⚠️ 应用题前提成立：追及题后车必须更快；问"几小时追上"时不能只把答案改成"无法确定"
- [ ] ⚠️ 单位/进率/近似数边界正确：改写是否用除法、四舍五入最大最小是否算对
- [ ] ⚠️ 数位与计数单位正确：小数点右第一位是十分位，第二位是百分位
- [ ] ⚠️ 图形变换不凭直觉：长方形拉成平行四边形面积变小；"沿高剪成两个直角三角形"通常不成立
- [ ] ⚠️ 条件充分：交集/并集是否重叠、平均数差值的份数、整数角度等前提是否写全
- [ ] ⚠️ 选项唯一：多个选项在数学上都成立必须改题（如 `0.450` 与 `0.4500` 都等于 `0.45`）
- [ ] ⚠️ `steps` 详细过程与答案一致：数值、方向、结论不能是上一题残留
- [ ] 低年级不引入未学概念（如四年级出现负数结果、五六年级内容）
- [ ] 运行 `python3 tests/check_answers.py`，语义规则全绿且做过植入测试

## 三、交互层（脚本巡检）

- [ ] ⚠️ **页面文本里没有 `[object ...]`**——DOM 元素被当字符串拼接了。
      渲染后扫叶子节点文本，命中 `[object ` 即失败（静态扫不出来）
- [ ] ⚠️ **数字一致性**：单元徽章、总览页卡片、实际内容三者对得上
      （徽章「N 个动画模块」== nav 里 `#s-` 的个数；徽章/总览的题数 == 实际题数；
      总览写"分三档"而实际有四档 → 都要报错）
- [ ] ⚠️ **上册/旧课件也要有这道检查**——新增验收层后要**回灌**到已有课件
- [ ] ⚠️ **解析数据解析条数对账**：`len(解析出的题数)` == `len(re.findall(r"\{\s*q:", body))`
      （对不上 = 正则漏配，校验会静默放过）
- [ ] ⚠️ **分步演示的"结论态"可达**——点"完整演示"后能看到该模块的教学口径总结
      （`step` 被夹在 `length-1`、渲染却判断 `>= length` 是常见成因）
- [ ] 星级标签正确：巩固/动手=★★★，扩展=★★★★，五星挑战=★★★★★
- [ ] ⚠️ **难度题（★★★★★）右侧有"数学思维提示"**（考点 + 易错提醒），
      写的是**思维方法**和**具体错法**，不是知识点名称或"要细心"
- [ ] ⚠️ **五星题答错时给出分步解题过程**，且**最后一步默认折叠**
      （折叠内容不参与"答错是否泄露答案"的判定，判定要按可见文字 + 词边界）
- [ ] 庆祝效果不刷屏：同屏点赞有上限、横幅同时只有一条、通关庆祝只触发一次
- [ ] 音效**不引用任何外部音频文件**（用 Web Audio 合成），动画**不引外部库**

- [ ] ⚠️ 控制台 **零 error、零 pageerror**
- [ ] 所有按钮/滑块可点、可复位；动画能暂停与重播
- [ ] 计分正确；每组**独立重做**（不刷新整页）
- [ ] 答错只给提示、**不泄露答案**；答对给说理式解析
- [ ] 填空答案归一化（"180/180度/180°" 都算对）
- [ ] 打印模式下按钮隐藏、答案区可见

## 四、视觉层（几何断言 + 截图）

- [ ] ⚠️ **图形方向/比例正确**（几何断言，不靠肉眼看）
- [ ] ⚠️ 大角度/极值时图形与标注**不出画布**
- [ ] ⚠️ 圆周数字不重叠；被压住的文字有描边光晕；标注在图形**外侧**
- [ ] 整圆等退化场景已特判（元素不消失）
- [ ] 每个 section 截图人工过目：排版、留白、对比度、投屏可读性（正文 ≥15px，图内文字 ≥12px）
- [ ] 动画与静态截图一致（参数改了图形跟着变，没有"改了参数没反应"）
