# 交付前自检清单

四层验收：**结构 → 内容 → 交互 → 视觉**。带 ⚠️ 的是实战踩过的坑。

## 〇、交付物

- [ ] `index.html`（主课件）、`教案.md`、`README.md`、`preview.png`、`tests/`
- [ ] ⚠️ 课件**不引用任何外部资源**（CDN/字体/图片外链）——断网、投影、家长手机都要能开
- [ ] 打印样式生效：隐藏导航与按钮，题目不跨页断开，答案区可展开
- [ ] 相对路径引用（整体移动目录后不失效）
- [ ] 路径已登记到所在平台/目录（如 education 平台的左侧目录）

## 一、结构层（脚本可查）

- [ ] ⚠️ 无外部引用：`grep -E '(src|href)\s*=\s*["'"'"']https?://' index.html` 无命中
      （SVG 命名空间 `http://www.w3.org/2000/svg` 不是网络请求，不用排除）
- [ ] 字体用系统栈、图标用 emoji 或内联 SVG
- [ ] HTML 有 `lang="zh-CN"`、`<title>`、viewport

## 二、内容层（脚本可查 + 人工核）

- [ ] ⚠️ **口径先定死**，且三条链路同源：**课件演示 → 练习题干 → 答案解析 → 教案表述**
- [ ] ⚠️ 题目数 = 答案条目数 = 解析数（脚本比对）
- [ ] 术语表述准确、无自相矛盾（例：写角时中间字母是顶点，`∠AOB` 与 `∠BOA` 是同一个角）
- [ ] 图形上的数值与文案一致（图标 45°，文字别写 40°）
- [ ] 教案内的时间分配、作业量与真实课时匹配
- [ ] 常见错误表来自真实错误反馈，不是编的

## 三、交互层（脚本巡检）

- [ ] ⚠️ 控制台 **零 error、零 pageerror**
- [ ] 所有按钮/滑块可点、可复位；动画能暂停与重播
- [ ] 计分正确；每组**独立重做**（不刷新整页）
- [ ] 答错只给提示、**不泄露答案**；答对给说理式解析
- [ ] 填空答案归一化（"180/180度/180°" 都算对）
- [ ] 打印模式下按钮隐藏、答案区可见

## 四、视觉层（几何断言 + 截图）

- [ ] ⚠️ **图形方向/比例正确**（几何断言，不靠肉眼看）
- [ ] ⚠️ 大角度/极值时图形与标注**不出画布**
- [ ] ⚠️ 圆周数字不重叠；被压住的文字有描边光晕；标注在图形**外侧**
- [ ] 整圆等退化场景已特判（元素不消失）
- [ ] 每个 section 截图人工过目：排版、留白、对比度、投屏可读性（正文 ≥15px，图内文字 ≥12px）
- [ ] 动画与静态截图一致（参数改了图形跟着变，没有"改了参数没反应"）
